# Κατάλογος και συγκεντρωτικές προβολές

Ο δομημένος κατάλογος πηγών είναι το:

```text
catalog/sources.csv
```

Το `catalog/sources.md` είναι η αναγνώσιμη προβολή που παράγουν οι υπάρχοντες αυτοματισμοί.

Για χρήση ως ενιαίο «αρχείο» πρώτης πρόσβασης, το repository παράγει επίσης στη ρίζα:

```text
SOURCE_ARCHIVE.md
```

Το αρχείο αυτό περιλαμβάνει:

- σύνοψη ανά τύπο πηγής,
- σύνοψη ανά κατηγορία/tag,
- σύνοψη κατάστασης,
- πλήρη πίνακα όλων των ενεργών πηγών,
- τίτλο, συγγραφείς, έτος, τύπο, κατηγορίες, κατάσταση, επιβεβαίωση και προτεραιότητα,
- σύνδεση με το πλήρες Markdown στον ενιαίο φάκελο `sources/`,
- εξωτερικό URL και σημειώσεις.

Το `SOURCE_ARCHIVE.md` είναι generated αρχείο και δεν πρέπει να διορθώνεται χειροκίνητα. Οι διορθώσεις γίνονται στον κατάλογο ή στα εργαλεία εισαγωγής και μετά εκτελείται:

```bash
python tools/aggregates.py
```
