# Μητρώο επιλογής για τη διπλωματική

Το `thesis-selection.csv` είναι η μοναδική πύλη εξαγωγής προς το `resilient-ai-agents-thesis`.

## Πεδία

| Πεδίο | Επιτρεπτές τιμές / χρήση |
|---|---|
| `Κωδικός` | υπαρκτός κωδικός `SRC-*` από τον κύριο κατάλογο |
| `Ρόλος` | `κύρια`, `υποστηρικτική`, `υπόβαθρο`, `απόρριψη` |
| `Κατάσταση` | `προς ανάλυση`, `πρόχειρη`, `επαληθευμένη`, `απορρίφθηκε` |
| `Κεφάλαια` | κεφάλαια ή ενότητες όπου μπορεί να χρησιμοποιηθεί |
| `Θέματα` | ελεγχόμενες θεματικές ετικέτες |
| `Εξαγωγή` | `ναι` μόνο όταν η ανάλυση και τα αποσπάσματα έχουν επαληθευτεί |
| `Σημείωση` | αιτιολόγηση επιλογής, αποκλεισμού ή εκκρεμότητας |

## Κανόνας ασφαλείας

Για `Εξαγωγή=ναι` απαιτούνται ταυτόχρονα:

1. `Κατάσταση=επαληθευμένη`,
2. ρόλος διαφορετικός από `απόρριψη`,
3. `analyses/SRC-*.md` με όλες τις υποχρεωτικές ενότητες,
4. `evidence/SRC-*.md` με επαληθευμένη κατάσταση,
5. ακριβής θέση και σαφής ισχυρισμός για κάθε τεκμήριο.

Το `tools/export_thesis.py` απορρίπτει την εξαγωγή όταν παραβιάζεται οποιοσδήποτε από αυτούς τους κανόνες.
