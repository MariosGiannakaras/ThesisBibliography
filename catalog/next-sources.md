# Επόμενες πηγές

Η λίστα περιέχει μόνο στοχευμένες ελλείψεις και αναφορές που εμφανίζονται σε τουλάχιστον δύο υπάρχουσες πηγές.

## Βασικές ελλείψεις

- [x] [AI Safety Gridworlds](https://arxiv.org/abs/1711.09883) — benchmark ασφάλειας σε GridWorld
- [x] [NovGrid: A Flexible Grid World for Evaluating Agent Response to Novelty](https://arxiv.org/abs/2203.12117) — καινοτομία, πτώση επίδοσης και ανάκαμψη
- [x] [CARL: A Benchmark for Contextual and Adaptive Reinforcement Learning](https://arxiv.org/abs/2110.02102) — μεταβολές περιβάλλοντος και προσαρμογή
- [x] [Robust Gymnasium: A Unified Modular Benchmark for Robust Reinforcement Learning](https://openreview.net/forum?id=2uQBSa2X4R) — ενιαίο benchmark αβεβαιότητας
- [x] [Deep Reinforcement Learning at the Edge of the Statistical Precipice](https://arxiv.org/abs/2108.13264) — αξιόπιστη στατιστική αξιολόγηση
- [x] [Action Robust Reinforcement Learning and Applications in Continuous Control](https://arxiv.org/abs/1901.09184) — αβεβαιότητα εκτέλεσης ενεργειών
- [x] [Robust Deep Reinforcement Learning against Adversarial Perturbations on State Observations](https://arxiv.org/abs/2003.08938) — αβεβαιότητα και επιθέσεις στις παρατηρήσεις
- [x] [Restarted Bayesian Online Change-point Detection for Non-Stationary Markov Decision Processes](https://proceedings.mlr.press/v232/alami23a.html) — ανίχνευση αλλαγών σε μη στάσιμα MDP
