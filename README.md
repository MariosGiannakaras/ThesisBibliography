# 📚 Βιβλιογραφία διπλωματικής

Κεντρικό repository συλλογής, καθαρισμού, οργάνωσης, ανάλυσης και επιλογής των πηγών για τη διπλωματική:

> **Σύγκριση και Αξιολόγηση Ανθεκτικών Πρακτόρων Τεχνητής Νοημοσύνης σε Περιβάλλοντα με Αβεβαιότητα**

Το `ThesisBibliography` είναι η μοναδική πηγή αλήθειας για τη βιβλιογραφία. Εδώ διατηρούνται τα πρωτότυπα, τα μεταδεδομένα, οι πλήρεις πηγές Markdown, οι κριτικές αναλύσεις και τα επαληθευμένα αποσπάσματα.

Το `resilient-ai-agents-thesis` δεν αντιγράφει ολόκληρη τη συλλογή. Λαμβάνει μόνο το ελεγχόμενο `πακέτο-διπλωματικής/` με επιλεγμένες και επαληθευμένες πηγές.

---

## Τρέχουσα κατάσταση πρωτοτύπων

Η συλλογή πρωτοτύπων έχει οριστικοποιηθεί:

- κάθε ενεργή πηγή έχει PDF, επαληθεύσιμο σύνδεσμο ή ουσιαστικό χρήσιμο περιεχόμενο,
- πηγές χωρίς PDF ή URL δεν διαγράφονται όταν έχουν αξιοποιήσιμες πληροφορίες,
- πραγματικά κενές εγγραφές αφαιρούνται,
- μη τεκμηριωμένα εισερχόμενα PDF δεν διατηρούνται,
- δεν υπάρχει μόνιμη ουρά εκκρεμών πρωτοτύπων.

Η συνολική κατάσταση εμφανίζεται στο `κατάλογος/πρωτότυπα.md`.

---

## 1. Προσθήκη νέων πηγών

Αντέγραψε Markdown, exports του NotebookLM ή συνοδευτικά αρχεία στο:

```text
νέες-πηγές/
```

και κάνε commit/push. Ο αυτοματισμός:

1. εισάγει τις πραγματικές πηγές,
2. αγνοεί προσωρινά audits και reports,
3. εξάγει και επιβεβαιώνει μεταδεδομένα όπου γίνεται,
4. διορθώνει γενικούς ή λανθασμένους τίτλους,
5. συγχωνεύει μόνο βέβαια διπλότυπα,
6. ενημερώνει τους καταλόγους,
7. συνδέει ή αναζητά νόμιμα διαθέσιμα πρωτότυπα,
8. εφαρμόζει την τελική πολιτική διατήρησης περιεχομένου.

---

## 2. Προσθήκη PDF

Βάλε PDF οποιασδήποτε ονομασίας προσωρινά στο:

```text
νέα-πρωτότυπα/
```

Ο αυτοματισμός δοκιμάζει:

1. κωδικό `SRC-*` στο όνομα,
2. DOI ή arXiv ID μέσα στο PDF,
3. μοναδική ισχυρή αντιστοίχιση τίτλου,
4. ασφαλή δημιουργία νέας πηγής μόνο με επαρκή στοιχεία.

Ασφαλής αντιστοίχιση αποθηκεύεται ως:

```text
πρωτότυπα/SRC-XXXXXXXXXX.pdf
```

Τα PDF παρακολουθούνται από Git LFS. YouTube, ιστοσελίδες και repositories αποθηκεύονται ως μικρά αρχεία `.url`. Paywalls, CAPTCHA και login δεν παρακάμπτονται.

---

## 3. Ανάλυση κάθε πηγής

Η ύπαρξη PDF ή πλήρους Markdown δεν σημαίνει ότι η πηγή έχει αναλυθεί.

Για κάθε πηγή δημιουργείται σταδιακά:

```text
αναλύσεις/SRC-XXXXXXXXXX.md
```

με:

- βιβλιογραφική ταυτότητα και ακριβή έκδοση,
- σκοπό και ερευνητικό ερώτημα,
- μεθοδολογία, δεδομένα, baselines και μετρικές,
- κύρια ευρήματα με ακριβείς θέσεις,
- υποθέσεις και ορισμούς,
- περιορισμούς και απειλές εγκυρότητας,
- σχέση με άλλες πηγές,
- προτεινόμενη χρήση και μη επιτρεπτές υπερερμηνείες.

Χρησιμοποίησε το `πρότυπα/ανάλυση-πηγής.md`.

Η πλήρης ουρά όλων των πηγών παράγεται στα:

```text
κατάλογος/κατάσταση-αναλύσεων.md
κατάλογος/κατάσταση-αναλύσεων.csv
```

---

## 4. Επαληθευμένα αποσπάσματα

Για κάθε αναλυμένη πηγή δημιουργείται:

```text
αποσπάσματα/SRC-XXXXXXXXXX.md
```

Κάθε τεκμήριο πρέπει να περιλαμβάνει:

- ακριβή σελίδα, ενότητα, πίνακα, σχήμα ή χρονική σήμανση,
- σύντομο παράθεμα ή πιστή παράφραση,
- τον ισχυρισμό που υποστηρίζει,
- συμφραζόμενα και περιορισμούς,
- προτεινόμενο κεφάλαιο,
- κατάσταση επαλήθευσης.

Οι παλαιότερες αυτόματες επιλογές είναι πρόχειρο υλικό και δεν εξάγονται μέχρι να ελεγχθούν στο πλήρες κείμενο. Χρησιμοποίησε το `πρότυπα/απόσπασμα-πηγής.md`.

---

## 5. Επιλογή για τη διπλωματική

Η μοναδική πύλη προς το κύριο repository είναι:

```text
κατάλογος/επιλογή-διπλωματικής.csv
```

Μια πηγή εξάγεται μόνο όταν:

1. υπάρχει στον κύριο κατάλογο,
2. έχει ρόλο `κύρια`, `υποστηρικτική` ή `υπόβαθρο`,
3. έχει `Κατάσταση=επαληθευμένη`,
4. έχει πλήρη επαληθευμένη ανάλυση,
5. έχει επαληθευμένα αποσπάσματα με ακριβή θέση και ισχυρισμό,
6. έχει `Εξαγωγή=ναι`.

Το `εργαλεία/εξαγωγή-διπλωματικής.py` απορρίπτει οποιαδήποτε μη ασφαλή επιλογή.

---

## 6. Πακέτο προς το κύριο repository

Το παραγόμενο:

```text
πακέτο-διπλωματικής/
```

περιλαμβάνει μόνο:

- `manifest.csv`,
- `SOURCE_COMMIT`,
- το επιλεγμένο υποσύνολο του καταλόγου,
- επαληθευμένες αναλύσεις,
- επαληθευμένα αποσπάσματα.

Δεν περιλαμβάνει PDF, Git LFS objects, ακατέργαστες μεταγραφές, πρόχειρες αναλύσεις ή μη επιλεγμένες πηγές.

Η σύνδεση των repositories περιγράφεται στο `συγχρονισμός/README.md`. Ο συγχρονισμός γίνεται pull-based, καρφιτσωμένος σε συγκεκριμένο commit και μέσω Pull Request στο κύριο repository.

## Κύρια δομή

```text
.
├── πηγές/                         # πλήρες Markdown ανά ενεργή πηγή
├── πρωτότυπα/                     # PDF μέσω Git LFS ή .url
├── αναλύσεις/                     # κριτική δομημένη ανάλυση
├── αποσπάσματα/                   # τεκμήρια και παραφράσεις
├── πρότυπα/                       # πρότυπα ανάλυσης και αποσπασμάτων
├── κατάλογος/
│   ├── πηγές.csv
│   ├── πηγές.md
│   ├── πρωτότυπα.csv
│   ├── πρωτότυπα.md
│   ├── κατάσταση-αναλύσεων.csv
│   ├── κατάσταση-αναλύσεων.md
│   ├── επιλογή-διπλωματικής.csv
│   └── επιλογή-διπλωματικής.md
├── πακέτο-διπλωματικής/           # generated, μόνο επαληθευμένο υλικό
├── συγχρονισμός/                  # συμβόλαιο και prompt κύριου repo
├── νέες-πηγές/                    # προσωρινά εισερχόμενα Markdown
├── νέα-πρωτότυπα/                 # προσωρινά εισερχόμενα PDF
└── εργαλεία/                      # αυτοματισμοί και validations
```

## Αυτοματισμοί

| Αυτοματισμός | Ρόλος |
|---|---|
| **Αυτόματη εισαγωγή πηγών** | εισαγωγή, μεταδεδομένα, καθαρισμός και πρώτη σύνδεση πρωτοτύπων |
| **Ενημέρωση πρωτοτύπων** | αντιστοίχιση εισερχόμενων PDF και οριστικοποίηση |
| **Πακέτο διπλωματικής** | ενημέρωση ουράς αναλύσεων και παραγωγή ελεγχόμενου πακέτου |
| **Ενημέρωση μεταδεδομένων** | επανέλεγχος βιβλιογραφικών στοιχείων |
| **Έλεγχος αποθετηρίου** | syntax, tests, δομή, migrations και ασφάλεια εξαγωγής |

## Προαιρετική τοπική εκτέλεση

```bash
git pull
git lfs install
python -m pip install pypdf
python εργαλεία/εισαγωγή.py
python εργαλεία/μεταδεδομένα.py
python εργαλεία/καθαρισμός-συνδέσεων.py
python εργαλεία/πρωτότυπα.py --download --limit 30
python εργαλεία/κατάσταση-αναλύσεων.py
python εργαλεία/εξαγωγή-διπλωματικής.py --validate-only
python εργαλεία/εξαγωγή-διπλωματικής.py
python εργαλεία/έλεγχος.py
```

## Κανόνας χρήσης στη διπλωματική

Μια πηγή χρησιμοποιείται ως παραπομπή μόνο όταν έχει ελεγχθεί η πραγματική έκδοση, έχει διαβαστεί το σχετικό πλήρες τμήμα, έχει καταγραφεί η ακριβής θέση του τεκμηρίου και έχει επιβεβαιωθεί ότι υποστηρίζει πράγματι τον συγκεκριμένο ισχυρισμό χωρίς υπερερμηνεία.
