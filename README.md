# 📚 Βιβλιογραφία διπλωματικής

Προσωρινός χώρος συλλογής, καθαρισμού και οργάνωσης των πηγών για τη διπλωματική:

> **Σύγκριση και Αξιολόγηση Ανθεκτικών Πρακτόρων Τεχνητής Νοημοσύνης σε Περιβάλλοντα με Αβεβαιότητα**

Το αποθετήριο δεν είναι η τελική βιβλιογραφία της εργασίας. Εδώ συγκεντρώνονται οι πηγές, διορθώνονται τα στοιχεία τους, συνδέονται με τα πρωτότυπα αρχεία και επιλέγονται αργότερα όσες αξίζει να μεταφερθούν στο κύριο repository.

---

## 🚀 Τι χρειάζεται να κάνεις

### Μία φορά στον υπολογιστή σου

Μέσα στον τοπικό φάκελο `ThesisBibliography` εκτέλεσε:

```bash
git pull
git lfs install
```

Το repository είναι ήδη ρυθμισμένο ώστε **όλα τα PDF να αποθηκεύονται μέσω Git LFS**. Δεν χρειάζεται να εκτελέσεις ξανά `git lfs track`.

## 1️⃣ Προσθήκη νέων πηγών από NotebookLM

Αντέγραψε οποιονδήποτε φάκελο με Markdown μέσα στο:

```text
νέες-πηγές/
```

Η δομή και τα ονόματα δεν έχουν σημασία. Ο φάκελος μπορεί να περιέχει:

- αρχεία `.md` από NotebookLM,
- συνοδευτικό audit ή report,
- πίνακες `.csv`,
- προαιρετικά PDF.

Παράδειγμα:

```text
νέες-πηγές/
└── οποιοδήποτε-όνομα/
    ├── πηγή-1.md
    ├── πηγή-2.md
    ├── Audit.md
    └── πίνακας.csv
```

Μετά:

```bash
git add νέες-πηγές
git commit -m "Νέες πηγές"
git push
```

Το GitHub αναλαμβάνει αυτόματα:

1. την εισαγωγή των πραγματικών πηγών,
2. την παράλειψη προσωρινών audits και reports,
3. την επιβεβαίωση τίτλου, συγγραφέων, έτους, DOI ή arXiv όπου γίνεται,
4. τη διόρθωση γενικών ονομάτων όπως `thesis.pdf` ή ονόματα URL,
5. τη συγχώνευση μόνο βέβαιων διπλοτύπων,
6. την ενημέρωση του καταλόγου,
7. την αναζήτηση και πρώτη λήψη δημόσιων πρωτοτύπων.

## 2️⃣ Προσθήκη PDF που έχεις ήδη κατεβάσει

Αν έχεις έναν άσχετα οργανωμένο φάκελο με πρωτότυπα PDF, αντέγραψέ τον ολόκληρο μέσα στο:

```text
νέα-πρωτότυπα/
```

Δεν χρειάζεται να μετονομάσεις τίποτα.

```text
νέα-πρωτότυπα/
└── ο-παλιός-μου-φάκελος/
    ├── thesis.pdf
    ├── paper-final.pdf
    └── 2203.12117.pdf
```

Μετά:

```bash
git add νέα-πρωτότυπα
git commit -m "Προσθήκη πρωτοτύπων"
git push
```

Ο αυτοματισμός προσπαθεί να συνδέσει κάθε PDF με την πραγματική πηγή χρησιμοποιώντας, κατά σειρά:

1. κωδικό `SRC-*` στο όνομα,
2. DOI ή arXiv ID μέσα στο PDF,
3. μοναδική και ισχυρή αντιστοίχιση του πραγματικού τίτλου.

Αν η σύνδεση είναι ασφαλής, το αρχείο αποθηκεύεται ως:

```text
πρωτότυπα/SRC-XXXXXXXXXX.pdf
```

Αν υπάρχουν δύο πιθανές αντιστοιχίσεις ή δεν διαβάζεται σωστά το PDF, δεν γίνεται αυθαίρετη σύνδεση. Το αρχείο παραμένει στο `νέα-πρωτότυπα/` και εμφανίζεται στην αναφορά για έλεγχο.

## 3️⃣ Τι κατεβαίνει αυτόματα

Ο αυτοματισμός επιχειρεί νόμιμη λήψη από δημόσια διαθέσιμες πηγές, όπως:

- arXiv,
- PMLR,
- OpenReview,
- ανοικτά πρακτικά συνεδρίων,
- πανεπιστημιακά αποθετήρια,
- επίσημα reports,
- ανοικτές εκδόσεις που εντοπίζονται μέσω DOI και OpenAlex.

Πριν αποθηκευτεί ένα αρχείο, ελέγχεται ότι είναι πραγματικό PDF και όχι:

- σελίδα CAPTCHA,
- «Verifying your browser»,
- HTML σφάλματος,
- κενό ή κατεστραμμένο αρχείο.

### YouTube, ιστοσελίδες και repositories

Δεν κατεβαίνουν ολόκληρα βίντεο ή ιστοσελίδες. Δημιουργείται μικρό αρχείο συντόμευσης:

```text
πρωτότυπα/SRC-XXXXXXXXXX.url
```

Έτσι διατηρείται ο πραγματικός σύνδεσμος χωρίς άχρηστα μεγάλα αρχεία.

### Πηγές με περιορισμένη πρόσβαση

Paywalls, login, CAPTCHA ή μη διαθέσιμα αρχεία δεν παρακάμπτονται. Καταγράφονται ως:

```text
χρειάζεται χειροκίνητη λήψη
```

| Αρχείο | Τι δείχνει |

| [`κατάλογος/πρωτότυπα.md`](κατάλογος/πρωτότυπα.md) | ποια πρωτότυπα βρέθηκαν, ποια λείπουν και ποια αρχεία δεν συνδέθηκαν |
| [`κατάλογος/προς-προσθήκη.md`](κατάλογος/προς-προσθήκη.md) | επόμενες πηγές και επαναλαμβανόμενες βιβλιογραφικές αναφορές |
| [`κατάλογος/έλεγχος-συνδέσεων.md`](κατάλογος/έλεγχος-συνδέσεων.md) | βέβαιες συγχωνεύσεις και διορθώσεις συνδέσεων |

Τα δύο τελευταία αρχεία δημιουργούνται ή ενημερώνονται από τον αυτοματισμό πρωτοτύπων.

## 🗂️ Απλή δομή

```text
.
├── README.md
├── πηγές/                    # ένα Markdown ανά ενεργή πηγή
├── πρωτότυπα/                # PDF μέσω Git LFS ή σύνδεσμοι .url
├── αποσπάσματα/              # χρήσιμα υποψήφια αποσπάσματα
├── κατάλογος/
│   ├── πηγές.md
│   ├── πηγές.csv
│   ├── προβληματικές-πηγές.md
│   ├── πρωτότυπα.md
│   ├── πρωτότυπα.csv
│   ├── έλεγχος-συνδέσεων.md
│   └── προς-προσθήκη.md
├── νέες-πηγές/               # εισερχόμενα Markdown/NotebookLM
├── νέα-πρωτότυπα/            # εισερχόμενα PDF οποιασδήποτε ονομασίας
└── εργαλεία/                 # αυτοματισμοί
```

Δεν διατηρούνται ενεργά:

- ομάδες NotebookLM,
- αρχικές διαδρομές groups,
- προσωρινά audits μετά την επεξεργασία,
- ξεχωριστές τεχνικές αναφορές διπλοτύπων,
- hashes και άλλα εσωτερικά στοιχεία στον κύριο κατάλογο.

## 🤖 Αυτοματισμοί GitHub

| Αυτοματισμός | Πότε εκτελείται | Τι κάνει |
|---|---|---|
| **Αυτόματη εισαγωγή πηγών** | όταν αλλάζει το `νέες-πηγές/` | εισαγωγή, μεταδεδομένα, καθαρισμός, σύνδεση και πρώτη λήψη πρωτοτύπων |
| **Ενημέρωση πρωτοτύπων** | όταν αλλάζει το `νέα-πρωτότυπα/`, καθημερινά ή χειροκίνητα | αντιστοίχιση PDF και επόμενη παρτίδα λήψεων |
| **Ενημέρωση μεταδεδομένων** | κάθε Κυριακή ή χειροκίνητα | επανέλεγχος εκκρεμών στοιχείων και επόμενων πηγών |
| **Έλεγχος αποθετηρίου** | σε Pull Requests και κανονικές αλλαγές | έλεγχος δομής, κωδικών, συνδέσεων και ονομάτων πρωτοτύπων |

Οι λήψεις γίνονται σε μικρές παρτίδες. Ο καθημερινός αυτοματισμός συνεχίζει από εκεί που σταμάτησε και δεν ξανακατεβάζει PDF που υπάρχουν ήδη.

## 🧰 Προαιρετική τοπική εκτέλεση

Δεν χρειάζεται για την κανονική χρήση. Για έλεγχο:

```bash
python -m pip install pypdf
python εργαλεία/εισαγωγή.py
python εργαλεία/μεταδεδομένα.py
python εργαλεία/διόρθωση-τίτλων.py
python εργαλεία/καθαρισμός-συνδέσεων.py
python εργαλεία/πρωτότυπα.py --download --limit 30
python εργαλεία/έλεγχος.py
```

Για να δεις ποια PDF παρακολουθούνται από το Git LFS:

```bash
git lfs ls-files
```

## ✅ Κανόνας χρήσης στη διπλωματική

Μια πηγή χρησιμοποιείται ως παραπομπή μόνο όταν:

1. επιβεβαιωθεί η πραγματική έκδοση και ο σύνδεσμός της,
2. διαβαστεί το σχετικό τμήμα του πλήρους κειμένου,
3. καταγραφεί η ακριβής σελίδα, ενότητα, εικόνα ή πίνακας,
4. ελεγχθεί ότι πράγματι υποστηρίζει τον ισχυρισμό της διπλωματικής.

Τα πρωτότυπα PDF αποτελούν αρχειακά αντίγραφα και χρησιμοποιούνται μόνο όταν χρειάζεται επαλήθευση. Η καθημερινή αναζήτηση και εργασία γίνεται στα Markdown και στα χρήσιμα αποσπάσματα.
