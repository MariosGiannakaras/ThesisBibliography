# Νέα πρωτότυπα

Αν έχεις PDF με οποιαδήποτε ονομασία, βάλε τα προσωρινά σε αυτόν τον φάκελο.

Δεν χρειάζεται:

- να τα μετονομάσεις,
- να γνωρίζεις τον κωδικό `SRC-*`,
- να τα χωρίσεις σε ομάδες,
- να τα αντιστοιχίσεις χειροκίνητα με τα Markdown,
- να τα μετατρέψεις πρώτα με NotebookLM ή άλλο εργαλείο.

Το `new-originals/` και το `new-sources/` τροφοδοτούν την **ίδια canonical intake διαδικασία**. Αν προστεθούν ταυτόχρονα Markdown και PDF, γίνεται μία σειριακή επεξεργασία και δημιουργείται ένα generated Pull Request, ώστε να μη δημιουργούνται επικαλυπτόμενες αλλαγές.

Ο αυτοματισμός δοκιμάζει, με αυτή τη σειρά:

1. κωδικό `SRC-*` στο όνομα,
2. DOI ή arXiv ID μέσα στο PDF,
3. μοναδική και ισχυρή αντιστοίχιση τίτλου,
4. δημιουργία νέας πηγής μόνο όταν τα στοιχεία είναι επαρκή και αξιόπιστα.

Αν το PDF είναι σαρωμένο ή δεν έχει επαρκές text layer, εφαρμόζεται OCR στις πρώτες σελίδες για την ταυτοποίηση. Το αρχικό PDF δεν τροποποιείται.

Όταν η αντιστοίχιση είναι ασφαλής, το αρχείο μεταφέρεται στο:

```text
originals/SRC-XXXXXXXXXX.pdf
```

Στη συνέχεια εκτελείται πλήρης μετατροπή όλων των σελίδων σε:

```text
sources/SRC-XXXXXXXXXX.md
```

Η μετατροπή:

- περνά από OCRmyPDF με `skip-text`, ώστε να διατηρούνται οι σελίδες που έχουν ήδη κείμενο και να OCR-άρονται οι σαρωμένες,
- καταγράφει σαφή όρια πραγματικών σελίδων,
- δεν αντικαθιστά υπάρχον ουσιαστικό Markdown,
- δηλώνει `further_conversion_required: ναι/όχι`,
- καταγράφει τις συγκεκριμένες αιτίες όταν χρειάζεται περαιτέρω τεχνική μετατροπή,
- απαιτεί πάντα ανθρώπινο έλεγχο πριν χρησιμοποιηθεί ως παραπομπή.

Η κατάσταση εμφανίζεται στα:

```text
catalog/conversion-status.md
catalog/conversion-status.csv
```

Όταν δεν υπάρχει ακόμη ασφαλής αντιστοίχιση, το PDF **δεν διαγράφεται**. Μεταφέρεται μόνιμα σε ASCII-safe tracked path:

```text
originals/unidentified/<SHA-prefix>__<ascii-safe-name>.pdf
```

Η αρχική ονομασία καταγράφεται στην αναφορά/σημείωση της αρχειοθέτησης, ενώ τα bytes του PDF παραμένουν αμετάβλητα. Έτσι μπορείς να ανεβάσεις ακόμη και αρχείο με ελληνικό ή άλλο Unicode όνομα χωρίς να επανεισαχθούν μη-ASCII canonical paths στο repository.

Η τελική πολιτική είναι:

- πηγή με PDF: διατηρείται μαζί με το αρχειακό πρωτότυπο,
- πηγή χωρίς PDF αλλά με επαληθεύσιμο URL: διατηρείται ως σύνδεσμος,
- πηγή χωρίς PDF ή URL αλλά με ουσιαστικό Markdown ή απόσπασμα: διατηρείται ως χρήσιμο περιεχόμενο,
- μη ταυτοποιημένο PDF: διατηρείται μόνιμα και επανεξετάζεται όταν προστεθούν νέα Markdown ή μεταδεδομένα,
- διαφορετικές εκδόσεις της ίδιας πηγής: διατηρούνται ως εναλλακτικές εκδόσεις,
- ακριβές αντίγραφο με ίδιο SHA-256 ή Git LFS object ID: αφαιρείται ως διπλότυπο,
- πραγματικά κενή εγγραφή χωρίς PDF, URL ή χρήσιμο περιεχόμενο: μπορεί να αφαιρεθεί.

Τα PDF παρακολουθούνται από το Git LFS. Το παρόν `README.md` διατηρείται πάντα.
