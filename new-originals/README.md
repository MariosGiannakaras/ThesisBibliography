# Νέα πρωτότυπα

Αν έχεις πρωτότυπο αρχείο πηγής με οποιαδήποτε ονομασία, βάλε το προσωρινά σε αυτόν τον φάκελο.

Υποστηρίζονται κατά κύριο λόγο:

- PDF,
- JATS/XML επιστημονικών άρθρων.

Δεν χρειάζεται:

- να τα μετονομάσεις,
- να γνωρίζεις τον κωδικό `SRC-*`,
- να τα χωρίσεις σε ομάδες,
- να τα αντιστοιχίσεις χειροκίνητα με τα Markdown,
- να τα μετατρέψεις πρώτα με NotebookLM ή άλλο εργαλείο.

Το `new-originals/` και το `new-sources/` τροφοδοτούν την **ίδια canonical intake διαδικασία**. Αν προστεθούν ταυτόχρονα Markdown/JATS και PDF, γίνεται μία σειριακή επεξεργασία και δημιουργείται ένα generated review branch, ώστε να μη δημιουργούνται επικαλυπτόμενες αλλαγές.

## PDF

Για PDF ο αυτοματισμός δοκιμάζει, με αυτή τη σειρά:

1. κωδικό `SRC-*` στο όνομα,
2. DOI ή arXiv ID μέσα στο PDF,
3. μοναδική και ισχυρή αντιστοίχιση τίτλου,
4. δημιουργία νέας πηγής μόνο όταν τα στοιχεία είναι επαρκή και αξιόπιστα.

Αν το PDF είναι σαρωμένο ή δεν έχει επαρκές text layer, εφαρμόζεται OCR για την ταυτοποίηση και μετατροπή. Το αρχικό PDF δεν τροποποιείται.

Όταν η αντιστοίχιση είναι ασφαλής, το κύριο PDF αποθηκεύεται ως `originals/SRC-XXXXXXXXXX.pdf`. Όταν δεν υπάρχει ασφαλής αντιστοίχιση, δεν διαγράφεται: αρχειοθετείται στο `originals/unidentified/` με content-derived ASCII-safe path.

## JATS/XML

Το αυθεντικό XML διατηρείται byte-for-byte στο `structured-originals/` με SHA-256 provenance. Αν αναγνωριστεί ως JATS article, το περιεχόμενο μετατρέπεται deterministic σε semantic Markdown χωρίς μετάφραση, με τίτλο, DOI, authors, year, abstract, sections και references, και μετά περνά από το κανονικό source pipeline.

Αν υπάρχει ήδη raw-JATS `.md` derivative για το ίδιο upload, το pipeline **δεν βασίζεται σε byte-for-byte ισότητα του derivative**. Ελέγχει πρώτα την επιστημονική ταυτότητα: DOI όταν υπάρχει, διαφορετικά πλήρη title/year/authors. Μόνο όταν η ταυτότητα συμπίπτει, το αυθεντικό XML θεωρείται authoritative και αντικαθιστά escaping/reformatting διαφορές του derivative. Αν οι ταυτότητες διαφέρουν ή δεν επαρκούν για ασφαλή αντιστοίχιση, το intake αποτυγχάνει κλειστά αντί να ενώσει διαφορετικές πηγές.

Μη-JATS XML δεν μετατρέπεται σε ψεύτικη βιβλιογραφική πηγή. Διατηρείται ως archival original και το χρήσιμο text εκτίθεται ως research-note material.

## Preservation policy

- πηγή με PDF: διατηρείται μαζί με το αρχειακό πρωτότυπο,
- JATS/XML: διατηρείται ως structured original και παράγεται canonical Markdown,
- πηγή χωρίς PDF αλλά με επαληθεύσιμο URL: διατηρείται ως σύνδεσμος,
- πηγή χωρίς PDF ή URL αλλά με ουσιαστικό Markdown ή απόσπασμα: διατηρείται ως χρήσιμο περιεχόμενο,
- μη ταυτοποιημένο PDF: διατηρείται μόνιμα και επανεξετάζεται,
- διαφορετικές εκδόσεις της ίδιας πηγής: διατηρούνται ως εναλλακτικές εκδόσεις,
- ακριβές byte-for-byte αντίγραφο με ίδιο SHA-256 ή ισοδύναμο Git LFS object ID: μπορεί να αφαιρεθεί ως διπλότυπο,
- πραγματικά κενή εγγραφή χωρίς original, URL ή χρήσιμο περιεχόμενο: μπορεί να αφαιρεθεί.

Τα PDF παρακολουθούνται από Git LFS. Τα structured textual originals παραμένουν κανονικά tracked text files στο `structured-originals/`. Το παρόν `README.md` διατηρείται πάντα.
