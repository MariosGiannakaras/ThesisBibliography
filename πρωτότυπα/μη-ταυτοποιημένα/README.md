# Μη ταυτοποιημένα πρωτότυπα

Σε αυτόν τον φάκελο αρχειοθετούνται μόνιμα τα PDF που δεν μπορούν ακόμη να συνδεθούν με ασφάλεια σε εγγραφή `SRC-*` ή να δημιουργήσουν αξιόπιστη νέα εγγραφή.

Τα αρχεία:

- διατηρούνται ακόμη και όταν δεν υπάρχει Markdown,
- επανεξετάζονται από τον αυτοματισμό όταν προστίθενται νέες πηγές ή μεταδεδομένα,
- μεταφέρονται σε κανονικό `SRC-*` αρχείο όταν προκύψει ασφαλής αντιστοίχιση,
- διαγράφονται μόνο όταν αποτελούν ακριβές αντίγραφο άλλου PDF με ίδιο SHA-256 ή Git LFS object ID.

Το πρόθεμα hash στο όνομα διατηρεί σταθερή ταυτότητα χωρίς να χάνεται το αρχικό όνομα του αρχείου.
