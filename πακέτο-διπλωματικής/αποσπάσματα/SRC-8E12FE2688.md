# Αποσπάσματα — Efficient Action Robust Reinforcement Learning with Probabilistic Policy Execution Uncertainty

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** Abstract και Introduction, PDF σελ. 1–2
- **Ισχυρισμός:** Η action uncertainty αφορά τη διαφορά ανάμεσα στην ενέργεια που επιλέγει ο agent και στην ενέργεια που τελικά εκτελείται.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο· Μοντέλο αβεβαιότητας
- **Θέματα:** action failure; policy execution uncertainty
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Με πιθανότητα `1-ρ` εκτελείται η intended action και με πιθανότητα `ρ` εκτελείται εναλλακτική δυσμενής action.

### Συμφραζόμενα

Η εργασία χρησιμοποιεί adversarial alternative action για να ορίσει worst-case robustness.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η φυσική αποτυχία συστήματος δεν είναι πάντοτε adversarial ή worst-case. Το μοντέλο είναι ελεγχόμενη πειραματική προσέγγιση.

### Προτεινόμενη χρήση

Ορισμός `intended_action`, `executed_action` και failure probability.

### Παραπομπή

Liu et al., 2024, Abstract και §1, PDF σελ. 1–2.

## Τεκμήριο E2

- **Τύπος:** πιστή παράφραση
- **Θέση:** Ενότητα 3, Eq. 3, PDF σελ. 3
- **Ισχυρισμός:** Το `ρ` λειτουργεί ως ρητή παράμετρος severity του policy-execution uncertainty.
- **Κεφάλαιο:** Πειραματικός σχεδιασμός
- **Θέματα:** severity; uncertainty set
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η actual behavior policy ανήκει σε uncertainty set γύρω από την intended policy και γράφεται ως κυρτός συνδυασμός agent και adversarial policy.

### Συμφραζόμενα

Το μοντέλο εφαρμόζεται σε finite-horizon episodic MDP.

### Περιορισμοί και κίνδυνος παρερμηνείας

Το `ρ` δεν είναι από μόνο του probability πραγματικής hardware βλάβης χωρίς calibration.

### Προτεινόμενη χρήση

Severity grid για action substitution στα pilots.

### Παραπομπή

Liu et al., 2024, §3, Eq. 3, PDF σελ. 3.

## Τεκμήριο E3

- **Τύπος:** πιστή παράφραση
- **Θέση:** Ενότητα 4, Theorem 1 και Eqs. 5–6, PDF σελ. 4
- **Ισχυρισμός:** Για το συγκεκριμένο uncertainty set υπάρχει deterministic optimal robust policy και Bellman-type recursion.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο
- **Θέματα:** robust Bellman equation; minimax policy
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η robust value συνδυάζει την καλύτερη intended action με τη χειρότερη εναλλακτική action, σταθμισμένες από `1-ρ` και `ρ`.

### Συμφραζόμενα

Το αποτέλεσμα ισχύει υπό τις finite tabular assumptions της εργασίας.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν αποδεικνύει αντίστοιχη ιδιότητα για arbitrary neural function approximation.

### Προτεινόμενη χρήση

Θεμελίωση robust tabular baseline.

### Παραπομπή

Liu et al., 2024, §4, Theorem 1, Eqs. 5–6, PDF σελ. 4.

## Τεκμήριο E4

- **Τύπος:** πιστή παράφραση
- **Θέση:** Ενότητα 8, PDF σελ. 8–9, Figures 3–4
- **Ισχυρισμός:** Training uncertainty και test-time perturbation πρέπει να καταγράφονται ως διαφορετικές παράμετροι.
- **Κεφάλαιο:** Πειραματικό πρωτόκολλο
- **Θέματα:** train-test mismatch; perturbation mode
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το ARRLC εκπαιδεύεται με uncertainty parameter `ρ=0.2`, ενώ η αξιολόγηση μεταβάλλει το test probability `p` και χρησιμοποιεί random ή fixed-adversarial substitutions.

### Συμφραζόμενα

Η αξιολόγηση γίνεται σε Cliff Walking και Inverted Pendulum, με Monte-Carlo average 100 trajectories.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δύο benchmarks δεν τεκμηριώνουν γενική superiority. Το δικό μας protocol πρέπει να χρησιμοποιεί πολλαπλά seeds και confidence intervals.

### Προτεινόμενη χρήση

Διαχωρισμός training robustness budget από deployment severity.

### Παραπομπή

Liu et al., 2024, §8, PDF σελ. 8–9.

## Τεκμήριο E5

- **Τύπος:** πιστή παράφραση
- **Θέση:** Ενότητες 8–9, PDF σελ. 9–10
- **Ισχυρισμός:** Στα συγκεκριμένα experiments, robust training βελτιώνει perturbed reward και convergence έναντι των αναφερόμενων baselines.
- **Κεφάλαιο:** Σχετικές εργασίες
- **Θέματα:** empirical robustness; baseline comparison
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το ARRLC υπερέχει του non-robust ORLC σε perturbed accumulated reward και συγκλίνει ταχύτερα από το robust TD baseline στα εξεταζόμενα settings.

### Συμφραζόμενα

Τα αποτελέσματα αφορούν συγκεκριμένη action-uncertainty formulation και fixed experimental design.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν επιτρέπεται να μεταφερθεί η κατάταξη ως αναμενόμενο αποτέλεσμα στο δικό μας GridWorld.

### Προτεινόμενη χρήση

Related-work evidence ότι pre-emptive robust optimization μπορεί να μειώσει degradation.

### Παραπομπή

Liu et al., 2024, §§8–9, PDF σελ. 9–10.

## Τεκμήριο E6

- **Τύπος:** κριτική σύνθεση από το ελεγμένο πρωτότυπο
- **Θέση:** συνολική formulation και experimental protocol, Ενότητες 3–9
- **Ισχυρισμός:** Η πηγή μετρά robustness υπό προκαθορισμένο uncertainty set και όχι resilience μέσω detection και online recovery.
- **Κεφάλαιο:** Ορισμοί· Threats to validity
- **Θέματα:** robustness; resilience boundary
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η policy εκπαιδεύεται ώστε να αποδίδει καλά υπό action substitutions. Δεν υπάρχει άγνωστο changepoint ούτε ξεχωριστή μέτρηση detection delay ή post-change adaptation trajectory.

### Συμφραζόμενα

Η διάκριση προκύπτει από το design της εργασίας, όχι από υποτίμηση της robust-RL συμβολής της.

### Περιορισμοί και κίνδυνος παρερμηνείας

Robustness μπορεί να αποτελεί συστατικό resilience, αλλά δεν αρκεί για να αποδειχθεί recovery.

### Προτεινόμενη χρήση

Αποφυγή ορολογικής σύγχυσης στο ερευνητικό ερώτημα.

### Παραπομπή

Liu et al., 2024, §§3–9.
