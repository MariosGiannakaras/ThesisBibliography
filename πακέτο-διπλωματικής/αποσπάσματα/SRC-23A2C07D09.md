# Αποσπάσματα — A Formal Verification Framework for Runtime Assurance

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** PDF σελ. 1–2, Abstract και Section 1.1
- **Ισχυρισμός:** Η Simplex Runtime Assurance αρχιτεκτονική επιτρέπει σε untrusted advanced controller να λειτουργεί υπό monitor και trusted reversionary controller.
- **Κεφάλαιο:** Σχετικές εργασίες; Agent architectures
- **Θέματα:** runtime assurance; simplex; black-box controller; fallback
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η εργασία περιγράφει σύστημα με advanced controller υψηλής δυνατότητας αλλά χωρίς πλήρη εμπιστοσύνη, runtime monitor και trusted reversionary controller. Όσο η monitor condition ισχύει χρησιμοποιείται ο advanced controller· όταν παραβιαστεί, ο έλεγχος περνά στο fallback.

### Συμφραζόμενα

Η RTA είναι design-time architecture που ενσωματώνει runtime verification με corrective action.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν αποδεικνύεται η ορθότητα του advanced controller. Αποδεικνύεται η συνολική safety μόνο υπό τις assumptions του monitor και του fallback.

### Προτεινόμενη χρήση

Να περιγραφεί πιθανός shielded-agent baseline με ξεχωριστή αναφορά advanced-policy και system-level αποτελεσμάτων.

### Παραπομπή

Slagel et al., Abstract και Section 1.1, PDF σελ. 1–2.

### Προτεινόμενη χρήση

## Τεκμήριο E3

- **Τύπος:** πιστή παράφραση
- **Θέση:** PDF σελ. 3–5, Section 2, Formula (1) και RTA proof rule
- **Ισχυρισμός:** Η safety της συνολικής RTA αρχιτεκτονικής ανάγεται σε αρχική condition, monitored advanced-controller obligation και trusted fallback obligation.
- **Κεφάλαιο:** Μεθοδολογία
- **Θέματα:** safety invariant; proof obligations; switching
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Ο γενικός proof rule απαιτεί η αρχική κατάσταση να είναι ασφαλής, κάθε monitored run του advanced component να διατηρεί την safety property και να φτάνει σε έγκυρη switch condition, και το reversionary component να διατηρεί την safety property όταν ξεκινά από αυτή τη switch condition.

### Συμφραζόμενα

Η σύνδεση γίνεται μέσω μιας ενδιάμεσης property που εξασφαλίζει ότι το fallback παραλαμβάνει το σύστημα σε recoverable κατάσταση.

### Περιορισμοί και κίνδυνος παρερμηνείας

Εάν η switch property είναι πολύ αδύναμη ή το fallback δεν μπορεί να ανακτήσει από αυτήν, η συνολική guarantee δεν ισχύει.

### Προτεινόμενη χρήση

Να μεταφραστεί σε GridWorld requirements: safe initialization, early warning set και αποδεδειγμένα ασφαλές fallback region.

### Παραπομπή

Slagel et al., Section 2, Formula (1) και RTA rule, PDF σελ. 3–5.

## Τεκμήριο E5

- **Τύπος:** πιστή παράφραση
- **Θέση:** PDF σελ. 4, Section 2, discussion of switchback
- **Ισχυρισμός:** Η επιστροφή από fallback σε advanced controller απαιτεί πρόσθετη condition και δεν λύνεται αυτόματα από το βασικό RTA framework.
- **Κεφάλαιο:** Περιορισμοί; Agent architectures
- **Θέματα:** switchback; recovery; hysteresis; fallback persistence
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η κύρια RTA formulation επιτρέπει στο reversionary component να λειτουργεί χωρίς να ορίζει γενικό switchback. Οι συγγραφείς περιγράφουν πώς θα μπορούσε να προστεθεί monitored switchback condition, αλλά απαιτούνται πρόσθετες invariant και reachability assumptions.

### Συμφραζόμενα

Η εργασία εστιάζει στην safety invariant και όχι στη βέλτιστη επιστροφή σε υψηλής απόδοσης λειτουργία.

### Περιορισμοί και κίνδυνος παρερμηνείας

Χωρίς explicit switchback, ένα σύστημα μπορεί να είναι ασφαλές αλλά να παραμένει μόνιμα σε χαμηλής απόδοσης fallback.

### Προτεινόμενη χρήση

Να μετρηθούν fallback dwell time, successful return rate και oscillatory switching.

### Παραπομπή

Slagel et al., Section 2, PDF σελ. 4.

## Τεκμήριο E6

- **Τύπος:** πιστή παράφραση
- **Θέση:** PDF σελ. 6–7, Section 4, Conclusion
- **Ισχυρισμός:** Η formalized RTA framework τεκμηριώνει safety assumptions, αλλά η εργασία δεν καλύπτει πλήρως industrial deployment ή σύνθετες concurrent architectures.
- **Κεφάλαιο:** Threats to validity
- **Θέματα:** scope; formal model; deployment gap
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το συμπέρασμα παρουσιάζει το framework και το braking proof-of-concept ως βάση για μελλοντικές πιο σύνθετες aerospace εφαρμογές, temporal properties και πολλαπλά reversionary components. Οι δυσκολίες industrial-scale RTA αναγνωρίζονται ως εκτός του παρόντος scope.

### Συμφραζόμενα

Το evidence αφορά formal architecture, όχι empirical comparison με adaptive RL agents.

### Περιορισμοί και κίνδυνος παρερμηνείας

Μια απλή implementation εμπνευσμένη από RTA δεν πρέπει να ονομαστεί formally verified χωρίς machine-checked proof ή exhaustive proof κατάλληλο για το finite model.

### Προτεινόμενη χρήση

Να παρουσιαστεί ως design pattern και προαιρετικό baseline, με σαφή δήλωση του επιπέδου verification που πραγματικά επιτεύχθηκε.

### Παραπομπή

Slagel et al., Section 4, PDF σελ. 6–7.
