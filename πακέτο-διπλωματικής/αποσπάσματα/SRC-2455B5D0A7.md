# Αποσπάσματα — A Comprehensive Survey on Test-Time Adaptation under Distribution Shifts

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** PDF σελ. 1–3, Abstract, Introduction και Figure 1
- **Ισχυρισμός:** Test-time adaptation χρησιμοποιεί target data για ενημέρωση κατά τη δοκιμή και επομένως δεν είναι frozen-policy zero-shot generalization.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο; Πειραματικό πρωτόκολλο
- **Θέματα:** test-time adaptation; domain generalization; test data
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η survey ορίζει την TTA ως προσαρμογή ενός pretrained source model με μη επισημασμένα target δεδομένα κατά τη test phase πριν ή κατά την παραγωγή προβλέψεων. Αντίθετα, domain generalization επιδιώκει απόδοση σε unseen domains χωρίς πρόσβαση σε test data για learning.

### Συμφραζόμενα

Η διάκριση αφορά supervised prediction, αλλά η λογική του information budget μεταφέρεται στο RL evaluation.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν πρέπει να παρουσιαστεί post-shift policy update ως zero-shot robustness. Είναι adaptation αποτέλεσμα.

### Προτεινόμενη χρήση

Να οριστεί πρώτα frozen evaluation και μετά ξεχωριστή adaptive phase.

### Παραπομπή

Liang et al., Abstract, Introduction και Figure 1, PDF σελ. 1–3.

## Τεκμήριο E2

- **Τύπος:** πιστή παράφραση
- **Θέση:** PDF σελ. 1–4, Introduction και taxonomy Figure 1
- **Ισχυρισμός:** TTDA, TTBA και OTTA διαφέρουν ως προς την ποσότητα, τη σειρά και την επαναχρησιμοποίηση των target δεδομένων.
- **Κεφάλαιο:** Σχετικές εργασίες; Μεθοδολογία
- **Θέματα:** TTDA; TTBA; OTTA; information budget
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η TTDA χρησιμοποιεί συνήθως ολόκληρο target domain και μπορεί να εκτελεί πολλαπλά adaptation epochs. Η TTBA προσαρμόζεται χωριστά σε ένα ή λίγα batches. Η OTTA επεξεργάζεται διαδοχικά streaming batches και μπορεί να μεταφέρει τις ενημερώσεις από προηγούμενα batches στα επόμενα.

### Συμφραζόμενα

Η taxonomy δείχνει ότι το «test-time adaptation» δεν είναι ένα ενιαίο protocol.

### Περιορισμοί και κίνδυνος παρερμηνείας

Αποτελέσματα από multi-epoch TTDA δεν είναι άμεσα συγκρίσιμα με one-pass online agent.

### Προτεινόμενη χρήση

Να δηλώνονται update frequency, replay, number of passes και reset policy για κάθε agent.

### Παραπομπή

Liang et al., Introduction και Figure 1, PDF σελ. 1–4.

## Τεκμήριο E3

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 5.1, Definition 5, Online Test-Time Adaptation
- **Ισχυρισμός:** Το OTTA λειτουργεί πάνω σε ακολουθία μη επισημασμένων mini-batches υπό distribution shift και πρέπει να σέβεται τη χρονική σειρά του stream.
- **Κεφάλαιο:** Πειραματικό πρωτόκολλο
- **Θέματα:** online adaptation; streaming data; causal evaluation
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Στο OTTA, ένα pretrained model λαμβάνει διαδοχικά target mini-batches και προσαρμόζεται ώστε να προβλέπει το τρέχον batch υπό shift. Η γνώση από παλαιότερα batches μπορεί να διατηρηθεί, αλλά μελλοντικά batches δεν πρέπει να χρησιμοποιούνται πριν εμφανιστούν.

### Συμφραζόμενα

Η definition είναι για classifiers, όχι για policies που επηρεάζουν ενεργά το data stream.

### Περιορισμοί και κίνδυνος παρερμηνείας

Στο RL απαιτείται πρόσθετη προσοχή, επειδή οι actions μεταβάλλουν τα επόμενα observations.

### Προτεινόμενη χρήση

Να εφαρμοστεί causal logging: κάθε update χρησιμοποιεί μόνο transitions που έχουν ήδη παραχθεί.

### Παραπομπή

Liang et al., Section 5.1, Definition 5.

## Τεκμήριο E4

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 5, discussion of continual test-time adaptation
- **Ισχυρισμός:** Continually changing target distributions μπορούν να προκαλέσουν error accumulation και catastrophic forgetting κατά την online adaptation.
- **Κεφάλαιο:** Μετρικές; Περιορισμοί
- **Θέματα:** catastrophic forgetting; error accumulation; continual shift
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Όταν τα test samples προέρχονται από διαδοχικά διαφορετικές distributions, οι online updates μπορούν να συσσωρεύσουν λάθη και να προκαλέσουν catastrophic forgetting. Η continual TTA βιβλιογραφία αναπτύσσει mechanisms για να περιορίσει αυτή την υποβάθμιση.

### Συμφραζόμενα

Η παρατήρηση αφορά self-adaptive classifiers και παρέχει γενικό failure mode, όχι RL-specific metric.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η βελτίωση στο τρέχον context δεν αποδεικνύει διατήρηση παλαιότερης γνώσης. Απαιτείται return-to-context test.

### Προτεινόμενη χρήση

Να μετρηθούν backward transfer, performance όταν επανέρχεται παλιό regime και cumulative adaptation failures.

### Παραπομπή

Liang et al., Section 5, continual TTA discussion.

## Τεκμήριο E5

- **Τύπος:** πιστή παράφραση
- **Θέση:** PDF σελ. 21 και εξής, Section 7, Emerging Trends and Open Problems
- **Ισχυρισμός:** Memory efficiency, on-the-fly operation και κοινό evaluation protocol παραμένουν ανοιχτά προβλήματα για continual TTA.
- **Κεφάλαιο:** Threats to validity; Υλοποίηση
- **Θέματα:** resource limits; protocol consistency; online deployment
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η survey επισημαίνει την ανάγκη για memory-efficient continual adaptation σε changing environments, για methods που δεν απαιτούν ειδικά προεκπαιδευμένο source model και για συνεπή evaluation protocols που δεν μεταφέρουν optimization μετά την παρατήρηση των τελικών αποτελεσμάτων.

### Συμφραζόμενα

Οι κατευθύνσεις αφορούν κυρίως perception deployments αλλά είναι χρήσιμες για resource-aware agent evaluation.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν παρέχονται κοινά resource budgets για RL agents. Αυτά πρέπει να καθοριστούν στην εργασία.

### Προτεινόμενη χρήση

Να αναφέρονται memory/replay size, update compute και wall-clock adaptation overhead μαζί με performance.

### Παραπομπή

Liang et al., Section 7, PDF σελ. 21 και εξής.
