# Νέα πρωτότυπα

Αν έχεις έναν φάκελο με PDF σε οποιαδήποτε ονομασία, αντέγραψέ τον ολόκληρο εδώ.

Δεν χρειάζεται:

- να μετονομάσεις τα αρχεία,
- να τα χωρίσεις σε ομάδες,
- να γνωρίζεις τον κωδικό `SRC-*`,
- να βάλεις κάθε PDF δίπλα στο αντίστοιχο Markdown.

Ο αυτοματισμός προσπαθεί να ταυτοποιήσει κάθε PDF με αυτή τη σειρά:

1. κωδικός `SRC-*` στο όνομα,
2. DOI ή arXiv ID μέσα στο PDF,
3. μοναδική ισχυρή αντιστοίχιση πραγματικού τίτλου.

Όταν η αντιστοίχιση είναι ασφαλής, το αρχείο μεταφέρεται ως:

```text
πρωτότυπα/SRC-XXXXXXXXXX.pdf
```

Αν υπάρχουν δύο πιθανές πηγές ή δεν διαβάζεται σωστά το PDF, το αρχείο μένει εδώ και εμφανίζεται στο `κατάλογος/πρωτότυπα.md` για χειροκίνητο έλεγχο.

Τα PDF παρακολουθούνται από το Git LFS.
