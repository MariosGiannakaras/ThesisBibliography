# Verified By-source Notes

Create one note only after the source has been identified and read sufficiently for its intended use.

Filename:

```text
<source-id>__notes.md
```

Required content:

- source ID and catalog record;
- verified full citation and version;
- source type and publication status;
- research question or purpose;
- method or theoretical contribution;
- environment, models, uncertainty mechanism and comparison conditions;
- metrics and statistical treatment;
- main reported findings;
- limitations and threats to validity;
- direct relevance to this thesis;
- candidate thesis chapter/claim;
- important figures, tables, equations and page/section markers;
- references worth screening;
- reviewer and review date.

Separate direct quotations, paraphrases and interpretation. Do not copy NotebookLM summaries into verified notes without checking the original source.
