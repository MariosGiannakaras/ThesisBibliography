# Verified By-source Notes

Create a note only after the source has been identified and read sufficiently for its intended use.

Use one file per source ID:

```text
<source-id>__notes.md
```

Required sections:

- Source ID and catalog link
- Full citation and verified version
- Source type and publication status
- Research question or purpose
- Method or theoretical contribution
- Experimental environment, models, datasets and comparison conditions
- Metrics and statistical treatment
- Main reported findings
- Limitations and threats to validity
- Direct relevance to this thesis
- Candidate chapter/use
- Important figures, tables, equations or page markers
- References from this source worth screening
- Reviewer and review date

Separate direct quotations, paraphrases and interpretation. Do not copy NotebookLM summaries as verified notes without checking the source.
