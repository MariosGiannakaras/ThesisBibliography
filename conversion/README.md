# Μετατροπή PDF σε Markdown

Το `tools/convert_pdf.py` μετατρέπει μόνο τα κύρια συνδεδεμένα πρωτότυπα `originals/SRC-XXXXXXXXXX.pdf` που δεν έχουν ήδη ουσιαστικό Markdown.

## Ροή

1. Το PDF περνά από OCRmyPDF με λειτουργία `skip-text` και γλώσσες `eng+ell`.
2. Το OCR γίνεται σε προσωρινό αντίγραφο. Το αρχειακό πρωτότυπο δεν μεταβάλλεται.
3. Εξάγεται κείμενο από όλες τις σελίδες.
4. Το Markdown περιλαμβάνει `<!-- PDF_PAGE: N -->` για ακριβή αντιστοίχιση σελίδων.
5. Υπολογίζονται δείκτες ποιότητας εξαγωγής.
6. Ενημερώνονται η πηγή, ο κατάλογος και οι αναφορές μετατροπής.

## Καταστάσεις

- `πλήρης-αυτόματη-προς-έλεγχο`: όλες οι σελίδες επεξεργάστηκαν και οι τεχνικοί δείκτες δεν δείχνουν σοβαρή απώλεια κειμένου.
- `χρειάζεται-περαιτέρω-μετατροπή`: εντοπίστηκαν κενές/πολύ σύντομες σελίδες, ανεπαρκές κείμενο, σφάλματα εξαγωγής, πολλοί μη αναγνωρίσιμοι χαρακτήρες ή αποτυχία OCR σε ήδη ανεπαρκές αποτέλεσμα.
- `υπάρχον-markdown-δεν-αντικαταστάθηκε`: υπάρχει ουσιαστικό Markdown από NotebookLM ή άλλη επεξεργασία και το εργαλείο δεν το αλλάζει.
- `εκκρεμεί-λήψη-lfs`: το πραγματικό PDF δεν ήταν διαθέσιμο στο συγκεκριμένο checkout.

Η ένδειξη `further_conversion_required` αφορά την τεχνική ποιότητα της μετατροπής. Η επιστημονική επαλήθευση και η παραγωγή αποσπασμάτων παραμένουν ξεχωριστά στάδια.

## Χειροκίνητη εκτέλεση

```bash
sudo apt-get install ocrmypdf tesseract-ocr-eng tesseract-ocr-ell
python -m pip install pypdf
python tools/convert_pdf.py
```
