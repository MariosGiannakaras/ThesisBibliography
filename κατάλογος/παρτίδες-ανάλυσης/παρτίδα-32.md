## Επιστημονικές αποφάσεις που κλειδώνουν

- **Scientific publication ≠ code repository.** Source code παραμένει για reproducibility/versioning αλλά δεν μετρά ως δεύτερη evidentiary unit.
- Η απόρριψη ενός GitHub record **δεν σημαίνει απόρριψη της underlying paper**· η paper αξιολογείται μόνο από δικό της primary full-text record.
- Umbrella dissertations που ενσωματώνουν δημοσιευμένα papers δεν μετρούν επιπλέον όταν τα thesis-specific claims μπορούν να στηριχθούν από τα primary papers.
- Environment/software choice και scientific algorithm evidence καταγράφονται σε χωριστά επίπεδα.
- Multi-agent/open-ended robustness δεν μεταφέρεται αυτομάτως σε single-agent controlled changepoint resilience.
