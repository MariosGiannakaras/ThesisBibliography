## Στόχος παρτίδας

Οριοθέτηση τριών εννοιών που επηρεάζουν άμεσα την ερμηνεία των experiments:

1. aleatoric έναντι epistemic/model uncertainty,
2. distribution-shift failure έναντι safe-exploration ή reward-specification failure,
3. continual adaptation έναντι transfer, zero-shot generalization και context recall.

## Κύριες αποφάσεις που υποστηρίζονται

1. Κάθε perturbation scenario θα δηλώνει αν η αβεβαιότητα είναι γνωστή στο agent, εκτιμώμενη ή άγνωστη.
2. `environment_stochasticity` και `model_uncertainty` θα καταγράφονται χωριστά.
3. Prediction error ή uncertainty spike δεν θα ονομάζεται calibrated detector χωρίς threshold, false-alarm και delay evaluation.
4. Robust policy και online resilience θα παραμένουν διαφορετικές ιδιότητες.
5. Safe-exploration cost θα αναφέρεται χωριστά από recovery performance.
6. Reward inversion ή αλλαγή κανόνα δεν θα χαρακτηρίζεται reward hacking· είναι externally induced non-stationarity.
7. Known-context recall, novel-context adaptation, frozen-policy generalization και continual update θα αποτελούν διαφορετικά evaluation regimes.
8. Context-library agents θα συγκρίνονται με no-transfer baseline για εντοπισμό negative transfer.

## Νέες απαιτήσεις πρωτοκόλλου

### Uncertainty declaration

- `uncertainty_source`: transition / observation / action / reward / latent context
- `uncertainty_type`: aleatoric / epistemic / mixed
- `agent_knows_distribution`: yes / no / partial
- `model_set_or_prior_available`: yes / no
- `uncertainty_reducible_by_interaction`: yes / no / partially

### Safety versus adaptation

- hazard visits ή constraint violations κατά το recovery window
- exploration-induced cost μετά από exploration reset
- return και safety cost σε χωριστές στήλες
- reward-specification failures εκτός βασικού benchmark, εκτός αν προστεθούν ρητά ως ξεχωριστό scenario family

### Transfer και recall

- `regime_status`: novel / previously_seen
- `adaptation_mode`: continual_update / frozen_generalization / context_inference / context_recall
- retrieval accuracy και wrong-context selection
- backward performance σε προηγούμενα regimes
- no-transfer comparator για negative transfer

## Επίδραση των νέων repository μηχανισμών

Η νέα OCR/conversion υποδομή βελτιώνει την ουρά εργασίας χωρίς να αλλάζει την επιστημονική μέθοδο:

- νέα PDF μπορούν να αποκτήσουν page-separated Markdown και conversion-quality status,
- υπάρχον canonical Markdown δεν αντικαθίσταται αυτόματα,
- πρωτότυπα χωρίς ασφαλή ταυτοποίηση διατηρούνται αντί να διαγράφονται,
- οι επιστημονικές αναλύσεις συνεχίζουν να δημιουργούνται μόνο μετά από χειροκίνητη/κριτική επαλήθευση της πηγής.

## Ανοιχτά σημεία

- Το conversion report πρέπει να χρησιμοποιείται ως triage signal και όχι ως ένδειξη επιστημονικής ποιότητας.
- OCR text με ένδειξη περαιτέρω μετατροπής δεν θα χρησιμοποιείται για citation-ready excerpts χωρίς έλεγχο στο PDF.
- Wrong-context recall θα πρέπει να αντιμετωπίζεται ως ιδιαίτερος failure mode, διαφορετικός από αργή continual adaptation.
