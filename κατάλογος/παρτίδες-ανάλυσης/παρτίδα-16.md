# Επιστημονική ανάλυση — Παρτίδα 16

## Στόχος

Διάκριση των failure modes που εμφανίζονται σε μακροχρόνια και repeated-change reinforcement learning:

1. catastrophic forgetting προηγούμενης γνώσης,
2. loss of plasticity — απώλεια ικανότητας νέας μάθησης,
3. interference ή negative transfer από προηγούμενα regimes,
4. stability–plasticity κόστος consolidation,
5. σωστή χρήση reset-from-scratch ως diagnostic baseline.

## Κύριες αποφάσεις που υποστηρίζονται

1. `forgetting`, `plasticity_loss` και `negative_transfer` θα είναι διαφορετικές κατηγορίες failure.
2. Η retention προηγούμενης policy δεν αρκεί: θα μετράται και η ταχύτητα/ποιότητα νέας μάθησης.
3. Σε repeated-change sequences, recovery metrics θα αναφέρονται ανά occurrence και όχι μόνο ως συνολικός μέσος όρος.
4. Full reset θα χρησιμοποιείται ως diagnostic baseline για καθαρή πλαστικότητα, όχι ως προτεινόμενος resilient agent.
5. Context recall και consolidation θα συγκρίνονται χωριστά: το πρώτο ανακαλεί discrete model, το δεύτερο περιορίζει συνεχή μετατόπιση μίας policy.
6. Negative reward δεν αποτελεί μόνο του αξιόπιστο forgetting ή change trigger.
7. Deep-network plasticity diagnostics δεν θα αποδίδονται σε tabular agents.
8. Bibliographic editions της ίδιας εργασίας δεν θα μετρώνται ως ανεξάρτητο evidence.

## Νέες απαιτήσεις πρωτοκόλλου

### Repeated-change evaluation

- `regime_occurrence_index`
- `recovery_time_by_occurrence`
- `post_change_plateau_by_occurrence`
- slope ή trend της recovery time σε επαναλήψεις
- slope ή trend της τελικής post-change επίδοσης
- first-visit έναντι revisit performance

### Retention, plasticity και interference

- **Retention:** backward performance σε probe episodes προηγούμενων regimes
- **Plasticity:** επίδοση/learning slope σε νέο regime σε σχέση με fresh-reset comparator
- **Interference:** διαφορά continual agent από matched scratch/no-transfer baseline
- `action_disagreement_on_probe_states`
- `relearning_deficit_auc`

### Reset comparator

Κάθε reset θα δηλώνει αν μηδενίζονται:

- Q-values ή policy weights,
- replay/history,
- optimizer state,
- counts/model estimates,
- exploration schedule,
- context library.

Ο idealized scratch comparator θα διακρίνεται από πραγματικό reset intervention μέσα στην ίδια run.

### Deep-agent diagnostics

Μόνο εφόσον χρησιμοποιηθεί neural agent:

- fraction ενεργών units,
- gradient norm,
- parameter/update norm,
- replay age distribution,
- optimizer-state reset status.

## Baseline implications

Το ελάχιστο matrix παραμένει resource-aware:

1. continual tabular Q-learning,
2. recency/decay Q-learning,
3. full reset,
4. detector-triggered reset,
5. context recall για recurring regimes.

Policy Consolidation ή CReLU-based deep agent δεν προστίθενται αυτόματα. Αποτελούν feasibility candidates μόνο αν το τελικό scope περιλαμβάνει neural policy/value networks.

## Ποιοτικοί περιορισμοί

- Το Switching ALE μεταβάλλει πολλά MDP στοιχεία μαζί και δεν αντικαθιστά controlled single-axis GridWorld tests.
- Τα Policy Consolidation experiments αφορούν PPO, continuous control και self-play.
- Η επίδοση σε πέντε πολύ ακριβά runs είναι ισχυρό failure demonstration αλλά όχι universal algorithm ranking.
- Το speculative forgetting-systems preprint δεν χρησιμοποιείται για claims ή implementation decisions.
