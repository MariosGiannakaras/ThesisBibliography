# Κατάλογος και συγκεντρωτικές προβολές

Ο δομημένος κατάλογος πηγών είναι το:

```text
κατάλογος/πηγές.csv
```

Το `κατάλογος/πηγές.md` είναι η αναγνώσιμη προβολή που παράγουν οι υπάρχοντες αυτοματισμοί.

Για χρήση ως ενιαίο «αρχείο» πρώτης πρόσβασης, το repository παράγει επίσης στη ρίζα:

```text
ΑΡΧΕΙΟ_ΠΗΓΩΝ.md
```

Το αρχείο αυτό περιλαμβάνει:

- σύνοψη ανά τύπο πηγής,
- σύνοψη ανά κατηγορία/tag,
- σύνοψη κατάστασης,
- πλήρη πίνακα όλων των ενεργών πηγών,
- τίτλο, συγγραφείς, έτος, τύπο, κατηγορίες, κατάσταση, επιβεβαίωση και προτεραιότητα,
- σύνδεση με το πλήρες Markdown στον ενιαίο φάκελο `πηγές/`,
- εξωτερικό URL και σημειώσεις.

Το `ΑΡΧΕΙΟ_ΠΗΓΩΝ.md` είναι generated αρχείο και δεν πρέπει να διορθώνεται χειροκίνητα. Οι διορθώσεις γίνονται στον κατάλογο ή στα εργαλεία εισαγωγής και μετά εκτελείται:

```bash
python εργαλεία/συγκεντρωτικά.py
```
