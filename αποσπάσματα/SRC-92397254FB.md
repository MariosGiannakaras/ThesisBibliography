# Επαληθευμένα τεκμήρια — SRC-92397254FB

## 1. Option interruption σε μεταβαλλόμενο περιβάλλον
- **Τύπος:** πιστή παράφραση
- **Θέση:** Sections 3.3–3.4
- **Ισχυρισμός:** Το I-QOption επιτρέπει πρόωρη διακοπή ενός option όταν η εκτιμώμενη αξία εναλλακτικής επιλογής υπερβαίνει την αξία συνέχισης του τρέχοντος option.
- **Κεφάλαιο:** Agent architectures / Adaptive baselines
- **Θέματα:** hierarchical RL; options; interruption; temporal abstraction
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση
Temporal abstraction δεν χρειάζεται να δεσμεύει τον agent μέχρι το αρχικό termination condition όταν το τρέχον state υποδηλώνει ότι το macro-action έχει γίνει ακατάλληλο.

### Προτεινόμενη χρήση
Option-interruption diagnostic μετά από environmental mismatch.

## 2. Dynamic GridWorld με μεταβαλλόμενα obstacles
- **Τύπος:** πιστή παράφραση
- **Θέση:** Sections 4.1–4.3
- **Ισχυρισμός:** Τα experiments χρησιμοποιούν four-room και six-room GridWorlds όπου πρόσθετα obstacles μεταβάλλονται μεταξύ episodes.
- **Κεφάλαιο:** Πειραματικό περιβάλλον
- **Θέματα:** GridWorld; dynamic obstacles; environment variation
- **Κατάσταση:** επαληθευμένο

### Περιορισμοί και κίνδυνος παρερμηνείας
Η αλλαγή γίνεται ανά episode και δεν αποτελεί hidden piecewise-stationary changepoint με ξεχωριστό detection event.

## 3. Early-learning advantage έναντι primitive Q-learning
- **Τύπος:** πιστή παράφραση
- **Θέση:** Sections 4.2–4.4, Figures 4–6
- **Ισχυρισμός:** Στα συγκεκριμένα experiments το I-QOption χρειάζεται λιγότερα steps-to-goal στις πρώτες episodes και εμφανίζει ελαφρώς ταχύτερη convergence από primitive Q-learning.
- **Κεφάλαιο:** Baselines / Results interpretation
- **Θέματα:** sample efficiency; convergence; Q-learning
- **Κατάσταση:** επαληθευμένο

### Περιορισμοί και κίνδυνος παρερμηνείας
Τα options είναι predefined και συνεπώς το I-QOption διαθέτει prior structural knowledge που δεν έχει ο primitive Q-learning baseline.

## 4. Prior option library ως capability advantage
- **Τύπος:** πιστή παράφραση
- **Θέση:** Sections 4.2–4.3
- **Ισχυρισμός:** Η four-room αξιολόγηση παρέχει έξι predefined options και η six-room δέκα.
- **Κεφάλαιο:** Experimental fairness
- **Θέματα:** prior knowledge; option library; fairness
- **Κατάσταση:** επαληθευμένο

### Προτεινόμενη χρήση
Κάθε hierarchical comparator πρέπει να δηλώνει/κοστολογεί την option library και να συγκρίνεται με capability-matched ablations.

## 5. Scope boundary
- **Τύπος:** πιστή παράφραση
- **Θέση:** Overall experimental design
- **Ισχυρισμός:** Η εργασία αξιολογεί dynamic obstacle variation και option interruption, όχι false alarms, changepoint detection delay ή repeated-regime recovery.
- **Κεφάλαιο:** Threats to validity
- **Θέματα:** changepoint boundary; resilience metrics
- **Κατάσταση:** επαληθευμένο
