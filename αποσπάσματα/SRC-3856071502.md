# Αποσπάσματα — Bayesian Online Changepoint Detection

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδα 1, Abstract και Section 1
- **Ισχυρισμός:** Ένας online Bayesian detector μπορεί να διατηρεί κατανομή πιθανότητας για τον χρόνο από την τελευταία αλλαγή, αντί να επιστρέφει μόνο δυαδική ειδοποίηση.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο — ανίχνευση αλλαγών
- **Θέματα:** posterior uncertainty, run length, online inference
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Οι Adams και MacKay ορίζουν το run length ως τον χρόνο που έχει παρέλθει από το πιο πρόσφατο changepoint και υπολογίζουν online την posterior distribution του, χρησιμοποιώντας μόνο τις έως τώρα παρατηρήσεις. Με αυτόν τον τρόπο η έξοδος δεν περιορίζεται σε ένα alarm, αλλά διατηρεί πολλαπλές πιθανές υποθέσεις για το πότε άλλαξε η generative process και πόσο βέβαιος είναι ο detector.

### Συμφραζόμενα

Η μέθοδος έχει σχεδιαστεί για causal predictive filtering σε sequential data. Η χρήση posterior uncertainty είναι χρήσιμη όταν η adaptation decision δεν πρέπει να ενεργοποιείται από μία μόνο θορυβώδη παρατήρηση.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η posterior είναι σωστή μόνο σε σχέση με το επιλεγμένο probabilistic model και prior. Δεν αποτελεί model-free βεβαιότητα ότι άλλαξε το πραγματικό MDP.

### Προτεινόμενη χρήση

Να στηρίξει την ιδέα ότι change detection confidence και adaptation trigger πρέπει να καταγράφονται χωριστά από την task performance.

### Παραπομπή

Adams and MacKay (2007), σελ. 1, Abstract και Section 1.

## Τεκμήριο E2

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδες 2–3, Sections 2–2.3 και Algorithm 1
- **Ισχυρισμός:** Η Bayesian online detection συνδυάζει prior για τη συχνότητα αλλαγών με predictive likelihood του νέου observation για κάθε πιθανό run length.
- **Κεφάλαιο:** Μεθοδολογία — change detector
- **Θέματα:** hazard function, predictive likelihood, message passing
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Σε κάθε timestep, probability mass είτε συνεχίζει σε run length r+1 είτε μεταφέρεται στο μηδέν, που αντιπροσωπεύει νέο changepoint. Η hazard function δίνει την prior πιθανότητα να λήξει το run, ενώ η predictive likelihood μετρά πόσο συμβατή είναι η νέα παρατήρηση με τα δεδομένα μετά το υποθετικό τελευταίο changepoint. Η posterior προκύπτει από recursive message passing και normalization με το evidence.

### Συμφραζόμενα

Με geometric prior το hazard είναι σταθερό 1/λ, άρα το λ κωδικοποιεί αναμενόμενη διάρκεια stationary segment. Αυτό είναι design assumption που πρέπει να αιτιολογείται ή να εξετάζεται σε sensitivity analysis.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η μέθοδος δεν είναι parameter-free. Λάθος hazard ή predictive model μπορεί να αλλάξει ουσιαστικά false positives, false negatives και detection delay.

### Προτεινόμενη χρήση

Να τεκμηριώσει calibration experiments για detector threshold/prior και να αποτρέψει ισχυρισμούς ότι detection confidence είναι ανεξάρτητο από assumptions.

### Παραπομπή

Adams and MacKay (2007), σελ. 2–3, Sections 2–2.3 και Algorithm 1.

## Τεκμήριο E3

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδα 3, Section 2.4 και Algorithm 1
- **Ισχυρισμός:** Η ακριβής online διατήρηση όλων των run-length hypotheses έχει γραμμικό worst-case κόστος ανά timestep, ενώ pruning μειώνει το μέσο κόστος εισάγοντας approximation threshold.
- **Κεφάλαιο:** Υλοποίηση και υπολογιστικοί περιορισμοί
- **Θέματα:** complexity, pruning, real-time detection
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Χωρίς truncation, ο αριθμός ενεργών run-length hypotheses αυξάνεται με το μήκος της ακολουθίας, άρα ο χρόνος και η μνήμη ανά βήμα είναι γραμμικά ως προς τις έως τότε παρατηρήσεις. Οι συγγραφείς προτείνουν απόρριψη posterior tail με πολύ μικρή συνολική mass, ώστε η average complexity να προσεγγίζει την αναμενόμενη διάρκεια run, ενώ το worst case παραμένει γραμμικό.

### Συμφραζόμενα

Για μικρό GridWorld το κόστος μπορεί να είναι αποδεκτό, αλλά σε πολλά parallel runs ή μακρές ακολουθίες πρέπει να καταγραφεί. Το pruning threshold γίνεται επιπλέον hyperparameter.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η αναφορά σε «constant average complexity» εξαρτάται από το expected run length και το truncation. Δεν είναι γενική εγγύηση σταθερού κόστους για οποιαδήποτε ακολουθία.

### Προτεινόμενη χρήση

Να χρησιμοποιηθεί στην επιλογή detector μόνο εφόσον το added complexity δικαιολογείται από το ερευνητικό ερώτημα.

### Παραπομπή

Adams and MacKay (2007), σελ. 3, Section 2.4.

## Τεκμήριο E4

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδες 3–5, Section 3, Figures 2–4
- **Ισχυρισμός:** Μετά από πιθανό changepoint η predictive uncertainty μπορεί να αυξηθεί επειδή τα δεδομένα του νέου segment είναι ακόμη λίγα.
- **Κεφάλαιο:** Αβεβαιότητα και ερμηνεία detector
- **Θέματα:** predictive variance, posterior reset, uncertainty
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Στο well-log παράδειγμα, οι posterior hypotheses επιστρέφουν σε μικρό run length γύρω από απότομες αλλαγές της μέσης τιμής. Αμέσως μετά την αλλαγή, η predictive variance αυξάνεται, όπως αναμένεται όταν ο detector θεωρεί ότι ξεκίνησε νέο segment και έχει περιορισμένα δεδομένα για την εκτίμηση των νέων parameters.

### Συμφραζόμενα

Το φαινόμενο είναι χρήσιμο για resilience: αμέσως μετά την αλλαγή, η policy ή ο detector πρέπει να θεωρεί τη νέα κατάσταση περισσότερο αβέβαιη, αλλά αυτό δεν υπαγορεύει συγκεκριμένη exploration strategy.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η παρατήρηση προέρχεται από fitted univariate statistical model και δεν αποδεικνύει ότι κάθε neural uncertainty estimator θα συμπεριφέρεται αντίστοιχα.

### Προτεινόμενη χρήση

Να υποστηρίξει logging uncertainty around change points και πιθανή σύγκριση confidence calibration.

### Παραπομπή

Adams and MacKay (2007), σελ. 3–5, Section 3 και Figures 2–4.

## Τεκμήριο E5

- **Τύπος:** αναλυτική παράφραση βασισμένη στο scope της μεθόδου
- **Θέση:** σελίδες 1–5, συνολικό scope και Section 4
- **Ισχυρισμός:** Η ανίχνευση changepoint δεν αποτελεί από μόνη της adaptation ή recovery· απαιτείται χωριστός μηχανισμός που μεταφράζει posterior evidence σε αλλαγή πολιτικής.
- **Κεφάλαιο:** Αρχιτεκτονική πειράματος και περιορισμοί
- **Θέματα:** detector–adapter separation, decision trigger, recovery
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η εργασία ολοκληρώνεται στην online inference και prediction: υπολογίζει posterior run length και predictive distribution, αλλά δεν περιλαμβάνει reinforcement-learning policy, retraining, exploration response ή μέτρηση task recovery. Επομένως, σε agent architecture ο BOCPD μπορεί να αποτελεί detector component, ενώ η adaptation policy και η αξιολόγηση της ανάκαμψης πρέπει να οριστούν ανεξάρτητα.

### Συμφραζόμενα

Αυτό είναι συμπέρασμα οριοθέτησης της πηγής, όχι αρνητική αξιολόγηση. Ο καθαρός διαχωρισμός μπορεί να βελτιώσει την πειραματική ερμηνεία.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν πρέπει να αποδοθούν στους Adams και MacKay συγκεκριμένες RL adaptation προτάσεις που δεν υπάρχουν στο paper.

### Προτεινόμενη χρήση

Να διαχωρίσει detector quality από agent recovery quality και να απαιτήσει ablation detector-only versus adaptation-enabled.

### Παραπομπή

Adams and MacKay (2007), συνολικό scope, Sections 1–4.
