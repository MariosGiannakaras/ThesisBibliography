# SRC-7313A97A30 — Επαληθευμένα τεκμήρια

## 1. Η επιλογή uncertainty set είναι αλγοριθμική απόφαση

Πολύ ευρύ ambiguity set μπορεί να περιλαμβάνει implausible MDPs και να παράγει υπερβολική συντηρητικότητα, ενώ πολύ στενό set δεν καλύπτει plausible mismatch. Η ακτίνα και οι exclusion rules πρέπει να αναφέρονται και να υποβάλλονται σε sensitivity analysis.

## 2. Tabular ARQ-like comparator

Η εργασία προτείνει robust Q-learning πάνω σε πιο περιορισμένο uncertainty set και δηλώνει finite-time bounds και convergence rate ίδιας τάξης με Q-learning variants. Αυτό στηρίζει feasibility pilot για tabular nominal-versus-practical-set comparison.

## 3. Nominal και pessimistic agent

Η double-agent αρχιτεκτονική διατηρεί πρόσθετη pessimistic εκτίμηση για model uncertainty. Η διαφορά nominal/pessimistic estimates και το compute overhead πρέπει να είναι observable diagnostics.

## 4. Conservativeness

Κάθε robust result πρέπει να συνοδεύεται από nominal clean return και conservativeness gap. Καλύτερο worst-case score χωρίς clean-condition report δεν αρκεί.

## 5. Scope boundary

Η μέθοδος δεν παρέχει explicit change detection, context recall ή repeated-regime recovery. Robustness ισχύει μόνο σε σχέση με το ορισμένο uncertainty set.
