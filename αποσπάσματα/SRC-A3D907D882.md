# Αποσπάσματα — Robust Gymnasium

## Τεκμήριο E1 — Ταξινομία σημείων διαταραχής

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελ. 3–5, Ενότητα 2.1, Σχήμα 2
- **Ισχυρισμός:** Ένα πείραμα ανθεκτικότητας πρέπει να ξεχωρίζει θόρυβο παρατήρησης ή ανταμοιβής, αποτυχία εκτέλεσης ενέργειας και αλλαγή του ίδιου του περιβάλλοντος.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο · Πειραματικό περιβάλλον
- **Θέματα:** perturbation taxonomy; observation noise; action failure; rule change
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το Disrupted-MDP τοποθετεί τρεις διαφορετικούς disruptors στην αλληλεπίδραση. Ο observation disruptor μετασχηματίζει την αληθινή κατάσταση ή ανταμοιβή σε αυτό που βλέπει ο πράκτορας. Ο action disruptor μετασχηματίζει την επιλεγμένη ενέργεια σε εκείνη που εκτελείται πραγματικά. Ο environment disruptor αλλάζει τη δυναμική μετάβασης ή τη συνάρτηση ανταμοιβής σε σχέση με το nominal περιβάλλον.

### Συμφραζόμενα

Η διάκριση δεν είναι απλή ονοματολογία. Καθορίζει ποια πληροφορία έχει ο agent, ποια απόφαση πήρε και ποια συνέπεια προκάλεσε το σύστημα. Στο δικό μας GridWorld πρέπει να αποθηκεύονται χωριστά true observation, observed observation, intended action, executed action και active environment version, ώστε η αιτία της υποβάθμισης να είναι αναγνωρίσιμη.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η πηγή δεν υποστηρίζει ότι όλοι οι πραγματικοί κίνδυνοι χωρούν τέλεια σε μία κατηγορία. Μια βλάβη μπορεί να επηρεάζει περισσότερα από ένα σημεία. Η ταξινομία πρέπει να χρησιμοποιηθεί για ελεγχόμενα πειράματα και όχι ως πλήρης οντολογία πραγματικών συστημάτων.

### Προτεινόμενη χρήση

Να αιτιολογήσει τις τρεις βασικές οικογένειες perturbations της διπλωματικής και το telemetry schema που διαχωρίζει πρόθεση, παρατήρηση, εκτέλεση και ενεργό κανόνα.

### Παραπομπή

Gu et al. (2025), Section 2.1, Figure 2, pp. 3–5.

## Τεκμήριο E2 — Mode, severity και frequency ως ανεξάρτητοι άξονες

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελ. 6–7, Ενότητες 3.2–3.3· Παράρτημα B.4, σελ. 20–21
- **Ισχυρισμός:** Η ίδια κατηγορία perturbation πρέπει να εξετάζεται σε πολλαπλές εντάσεις, τρόπους και συχνότητες εφαρμογής.
- **Κεφάλαιο:** Πειραματικό πρωτόκολλο
- **Θέματα:** severity; frequency; random disturbance; adversarial disturbance
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το benchmark διαχωρίζει τον στόχο της διαταραχής από τον τρόπο παραγωγής και το χρονικό της πρόγραμμα. Μια disturbance μπορεί να είναι τυχαία, αντιπαραθετική, εσωτερική μεταβολή δυναμικής ή εξωτερική παρέμβαση. Μπορεί επίσης να εφαρμόζεται σε κάθε βήμα, ανά επεισόδιο, αραιά ή μόνο κατά την αξιολόγηση. Τα συμπληρωματικά πειράματα δείχνουν ότι η συχνότητα επίθεσης επηρεάζει ουσιαστικά την επίδοση.

### Συμφραζόμενα

Για τη διπλωματική, μια μοναδική πιθανότητα action failure ή μία σταθερή τυπική απόκλιση θορύβου δεν είναι επαρκές πειραματικό πρωτόκολλο. Χρειάζεται μικρό, προδηλωμένο severity grid και τουλάχιστον χωριστές περιπτώσεις συνεχούς, επεισοδιακής και event-triggered perturbation. Η σύγκριση πρέπει να χρησιμοποιεί το ίδιο πρόγραμμα αλλαγών για όλους τους agents ανά seed.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν είναι απαραίτητο να αντιγραφούν όλες οι κατηγορίες ή οι αριθμητικές τιμές του benchmark. Υπερβολικά μεγάλο factorial design θα ήταν ασύμβατο με τον διαθέσιμο υπολογιστικό προϋπολογισμό. Η πηγή αιτιολογεί τους άξονες, όχι συγκεκριμένο πλήθος runs για τη δική μας μελέτη.

### Προτεινόμενη χρήση

Να στηρίξει τον ορισμό perturbation configuration ως σύνθεση target × mode × severity × frequency × onset και την ανάγκη ablation ανά άξονα.

### Παραπομπή

Gu et al. (2025), Sections 3.2–3.3, pp. 6–7; Appendix B.4, pp. 20–21.

## Τεκμήριο E3 — Nominal επίδοση και post-training robustness

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελ. 8–10, Ενότητες 4.1–4.4 και σχετικά σχήματα
- **Ισχυρισμός:** Υψηλή επίδοση στο nominal περιβάλλον δεν αποτελεί απόδειξη ανθεκτικότητας σε άγνωστες διαταραχές μετά την εκπαίδευση.
- **Κεφάλαιο:** Μετρικές · Αποτελέσματα · Threats to validity
- **Θέματα:** deployment robustness; post-training shift; baseline evaluation
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Στις συγκρίσεις του Robust Gymnasium, standard και εξειδικευμένοι αλγόριθμοι παρουσιάζουν σημαντικές ελλείψεις ακόμη και υπό single-stage disruptions. Η πτώση γίνεται ιδιαίτερα εμφανής όταν η perturbation δεν αποτελεί μέρος της εκπαίδευσης αλλά εισάγεται κατά το testing. Επιπλέον, η σχετική κατάταξη των μεθόδων αλλάζει ανάλογα με το αν διαταράσσεται state, action, reward ή environment dynamics.

### Συμφραζόμενα

Η δική μας σύγκριση πρέπει να αναφέρει χωριστά nominal performance, immediate degradation μετά το change point, worst-window performance, recovery trajectory και final adapted performance. Ένας agent που έχει χαμηλότερο nominal return αλλά μικρότερη πτώση ή ταχύτερη ανάκαμψη μπορεί να είναι πιο resilient, χωρίς να είναι συνολικά καλύτερος σε κάθε στόχο.

### Περιορισμοί και κίνδυνος παρερμηνείας

Το paper δεν ορίζει ενιαίο recovery time ούτε μελετά πάντα continued online learning μετά τη μεταβολή. Άρα δεν πρέπει να χρησιμοποιηθεί ως πηγή για συγκεκριμένο μαθηματικό ορισμό resilience. Υποστηρίζει την ανάγκη χωριστής deployment αξιολόγησης και πολλαπλών metrics.

### Προτεινόμενη χρήση

Να αιτιολογήσει το clean-vs-shift protocol και την απόρριψη ενός μοναδικού μέσου return ως συνολικού δείκτη ανθεκτικότητας.

### Παραπομπή

Gu et al. (2025), Sections 4.1–4.4, pp. 8–10.
