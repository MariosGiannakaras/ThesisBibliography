# Τεκμήρια

## 1. Epistemic uncertainty ως OOD signal
- Τύπος: πιστή παράφραση
- Θέση: Abstract, Introduction
- Ισχυρισμός: Η εργασία χρησιμοποιεί uncertainty του value-estimation network για διάκριση καταστάσεων που δεν καλύπτονται από τα δεδομένα εκπαίδευσης.
- Κεφάλαιο: Θεωρητικό υπόβαθρο / Detection
- Θέματα: epistemic uncertainty; OOD; value network
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Η epistemic uncertainty συνδέεται με έλλειψη δεδομένων και αναμένεται να είναι υψηλότερη σε περιοχές χαμηλής training-data density, επομένως μπορεί να χρησιμοποιηθεί ως σήμα OOD.

### Συμφραζόμενα
Η εργασία εστιάζει σε deep value-based RL και όχι σε tabular agent.

### Περιορισμοί και κίνδυνος παρερμηνείας
OOD score δεν ισοδυναμεί με calibrated probability ούτε με sequential changepoint detector.

### Προτεινόμενη χρήση
Για να αιτιολογηθεί optional uncertainty-based detector arm με ανεξάρτητη calibration/evaluation διαδικασία.

### Παραπομπή
Sedlmeier et al., arXiv:1901.02219.

## 2. Controlled GridWorld OOD split
- Τύπος: πιστή παράφραση
- Θέση: Section 3, Experimental Setup
- Ισχυρισμός: Το mirror GridWorld μετακινεί start/goal σε περιοχή που δεν επισκέφθηκε ο agent κατά την εκπαίδευση και τα evaluation trajectories δεν χρησιμοποιούνται για learning.
- Κεφάλαιο: Πειραματικό πρωτόκολλο
- Θέματα: GridWorld; OOD; leakage control
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Η εκπαίδευση γίνεται μόνο στο train environment, ενώ η OOD αξιολόγηση γίνεται σε mirror environment και τα δεδομένα της αξιολόγησης δεν επιστρέφουν στο training set.

### Συμφραζόμενα
Πρόκειται για static train/test shift και όχι για online αλλαγή μέσα σε ενιαίο επεισόδιο ή stream.

### Περιορισμοί και κίνδυνος παρερμηνείας
Δεν πρέπει να χρησιμοποιηθεί ως απόδειξη recovery μετά από changepoint.

### Προτεινόμενη χρήση
Για leakage-safe OOD diagnostic και held-out structural configurations.

### Παραπομπή
Sedlmeier et al., Section 3.

## 3. Bootstrap έναντι dropout
- Τύπος: πιστή παράφραση
- Θέση: Sections 4–5
- Ισχυρισμός: Τα bootstrap-based estimators έδωσαν πιο σταθερό ID/OOD separation από τα dropout-based estimators στο συγκεκριμένο experiment.
- Κεφάλαιο: Detection baselines
- Θέματα: bootstrap; MC dropout; uncertainty
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Τα BOOT/BOOTP μοντέλα διατήρησαν υψηλότερη uncertainty στο mirror environment, ενώ τα MC-dropout variants παρουσίασαν αντιστροφές και μη σταθερό separation κατά την εκπαίδευση.

### Συμφραζόμενα
Το εύρημα είναι environment- και architecture-specific.

### Περιορισμοί και κίνδυνος παρερμηνείας
Δεν τεκμηριώνει γενική υπεροχή ensembles σε κάθε RL detector.

### Προτεινόμενη χρήση
Ως rationale για να μην επιλεγεί estimator μόνο από θεωρητική δημοφιλία, αλλά μετά από held-out calibration και sequential metrics.

### Παραπομπή
Sedlmeier et al., Sections 4–5.
