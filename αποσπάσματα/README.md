# Επαληθευμένα αποσπάσματα

Κάθε αρχείο `αποσπάσματα/SRC-XXXXXXXXXX.md` συνδέεται με μία πηγή και περιέχει μόνο τεκμήρια που μπορούν να χρησιμοποιηθούν με ασφάλεια στη διπλωματική.

Ένα σωστό απόσπασμα δεν είναι τυχαία φράση ή αυτόματη επιλογή. Για κάθε στοιχείο απαιτούνται:

- ακριβής θέση: σελίδα, ενότητα, πίνακας, σχήμα ή χρονική σήμανση,
- τύπος: σύντομο άμεσο παράθεμα ή πιστή παράφραση,
- ο ισχυρισμός που υποστηρίζει,
- τα αναγκαία συμφραζόμενα,
- περιορισμοί και κίνδυνος παρερμηνείας,
- προτεινόμενο κεφάλαιο της διπλωματικής,
- κατάσταση επαλήθευσης.

Χρησιμοποίησε το `πρότυπα/απόσπασμα-πηγής.md`.

Οι παλαιότερες αυτόματες επιλογές θεωρούνται πρόχειρο υλικό μέχρι να ελεγχθούν στο πλήρες κείμενο. Μόνο αρχεία που δηλώνουν `Κατάσταση: επαληθευμένο` και έχουν αντίστοιχη επαληθευμένη ανάλυση μπορούν να μπουν στο πακέτο της διπλωματικής.

Τα άμεσα παραθέματα πρέπει να είναι σύντομα και απολύτως αναγκαία. Για τη συγγραφή προτιμάται τεκμηριωμένη παράφραση με ακριβή παραπομπή.
