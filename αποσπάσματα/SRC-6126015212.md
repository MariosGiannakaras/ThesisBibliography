# SRC-6126015212 — verified excerpts

## Unknown safety function

Η εργασία μελετά constrained MDP όπου η safety function δεν είναι γνωστή εκ των προτέρων. Η agent πρέπει να μάθει ποια states είναι ασφαλή χωρίς να παραβιάσει το safety threshold.

**Χρήση:** distinction από methods που θεωρούν known hazard map.

## Pessimistic safe set

Το pessimistic safe set περιλαμβάνει states που θεωρούνται ασφαλή με υψηλή confidence και επιπλέον ικανοποιούν reachability και returnability requirements.

**Thesis-ready claim:** local safety label ενός state δεν αρκεί· χρειάζεται ασφαλής πρόσβαση και δυνατότητα επιστροφής.

## Optimistic safe set

Το optimistic set περιλαμβάνει states που ενδέχεται να είναι ασφαλή και χρησιμοποιείται για guiding safety exploration.

**Protocol implication:** uncertain-safe states πρέπει να διαχωρίζονται από certified-safe states.

## Environmental-change implication

Μια structural αλλαγή μπορεί να ακυρώσει returnability ακόμη και αν τα per-state hazard labels δεν αλλάξουν.

**Χρήση:** μετά από blocked corridor/edge αλλαγή, η safe connectivity πρέπει να επανελέγχεται.

## Safety/reward trade-off

Η εργασία χωρίζει safety exploration από reward optimization και προτείνει early stopping ώστε να περιοριστεί η υπερβολική συλλογή safety information.

**Μετρικές:** safety-exploration steps, reward opportunity cost και latency μέχρι ασφαλή επανέναρξη task optimization.

## Scope boundary

Το SNO-MDP δεν αποτελεί γενικό changepoint detector και η GP/RKHS machinery δεν είναι αναγκαίο default implementation για tabular GridWorld.
