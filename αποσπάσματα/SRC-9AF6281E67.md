# Τεκμήρια

## 1. Rectangularity και συντηρητικότητα
- Τύπος: πιστή παράφραση
- Θέση: Abstract, Introduction
- Ισχυρισμός: Η ανεξάρτητη worst-case αντιμετώπιση ανά state/action μπορεί να οδηγεί σε υπερβολικά conservative robust policies.
- Κεφάλαιο: Robust baselines / Trade-offs
- Θέματα: rectangularity; conservativeness; robust MDP
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Η computationally convenient rectangularity μπορεί να παραβλέψει dependencies μεταξύ περιοχών του state space και να συνδυάσει ταυτόχρονα τοπικά worst cases που δεν υποστηρίζονται από τα διαθέσιμα trajectories.

### Συμφραζόμενα
Η εργασία προτείνει trajectory-feature constraints ως εναλλακτική.

### Περιορισμοί και κίνδυνος παρερμηνείας
Η non-rectangular formulation δεν είναι αυτομάτως καλύτερη· εξαρτάται από features, data και computation.

### Προτεινόμενη χρήση
Για uncertainty-set sensitivity analysis και nominal-versus-worst-case reporting.

### Παραπομπή
Tirinzoni et al., NeurIPS 2018.

## 2. Trajectory features ως prior structure
- Τύπος: πιστή παράφραση
- Θέση: Section 3
- Ισχυρισμός: Feature expectations από reference-policy trajectories μπορούν να ορίσουν global constraints που συνδέουν transition uncertainty σε πολλές καταστάσεις.
- Κεφάλαιο: Μοντέλο αβεβαιότητας
- Θέματα: trajectory features; reference policy; non-rectangular uncertainty
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Αντί ξεχωριστού uncertainty constraint για κάθε state-action pair, η μέθοδος απαιτεί οι υποψήφιες dynamics να αναπαράγουν επιλεγμένες aggregate ιδιότητες των trajectories.

### Συμφραζόμενα
Τα features πρέπει να κωδικοποιούν ουσιαστική γνώση του MDP.

### Περιορισμοί και κίνδυνος παρερμηνείας
Η feature επιλογή αποτελεί prior-information advantage και πρέπει να δηλώνεται.

### Προτεινόμενη χρήση
Για protocol field `uncertainty_set_construction` και `reference_policy_data_budget`.

### Παραπομπή
Tirinzoni et al., Section 3.
