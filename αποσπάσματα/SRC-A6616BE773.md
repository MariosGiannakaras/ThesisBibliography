# Αποσπάσματα — A Baseline for Detecting Misclassified and Out-of-Distribution Examples

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** Abstract και Section 1, σελ. 1–2
- **Ισχυρισμός:** Η μέγιστη softmax probability μπορεί να χρησιμοποιηθεί ως απλό baseline για ranking λάθος ή OOD examples.
- **Κεφάλαιο:** Σχετικές εργασίες
- **Θέματα:** OOD detection; softmax; baseline
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Σωστά ταξινομημένα και in-distribution examples τείνουν να εμφανίζουν υψηλότερη μέγιστη πιθανότητα softmax από λανθασμένα ή εκτός κατανομής examples, επιτρέποντας έναν απλό score-based detector.

### Συμφραζόμενα

Η εργασία παρουσιάζει το score ως baseline που πρέπει να ξεπεραστεί, όχι ως πλήρη λύση uncertainty quantification.

### Περιορισμοί και κίνδυνος παρερμηνείας

Το αποτέλεσμα αφορά classifiers και δεν αποδεικνύει ανίχνευση αλλαγής transition ή reward σε RL.

### Προτεινόμενη χρήση

Reference detector μόνο για learned observation representations.

### Παραπομπή

Hendrycks and Gimpel (2016), Abstract and Section 1, arXiv:1610.02136.

## Τεκμήριο E2

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 2, Problem Formulation and Evaluation, περίπου σελ. 2–3
- **Ισχυρισμός:** AUROC και AUPR είναι καταλληλότερες από απλή accuracy για score-based detection με άνισες base rates.
- **Κεφάλαιο:** Μετρικές
- **Θέματα:** AUROC; AUPR; class imbalance
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η accuracy απαιτεί threshold και μπορεί να είναι παραπλανητική όταν μία κλάση κυριαρχεί. Η AUROC αξιολογεί ranking ανεξάρτητα από συγκεκριμένο threshold, ενώ η AUPR επηρεάζεται από την prevalence της positive class και είναι χρήσιμη σε ανισόρροπες περιπτώσεις.

### Συμφραζόμενα

Οι συγγραφείς αναφέρουν AUPR και με τις δύο επιλογές positive class.

### Περιορισμοί και κίνδυνος παρερμηνείας

Οι μετρικές δεν ορίζουν deployment threshold ούτε κόστος καθυστέρησης και false alarms.

### Προτεινόμενη χρήση

Συμπληρωματικές detection metrics εφόσον υλοποιηθεί detector.

### Παραπομπή

Hendrycks and Gimpel (2016), Section 2, arXiv:1610.02136.

## Τεκμήριο E3

- **Τύπος:** πιστή παράφραση
- **Θέση:** Introduction και Tables 1–2, περίπου σελ. 1–5
- **Ισχυρισμός:** Η softmax probability δεν πρέπει να ερμηνεύεται ως καλιμπραρισμένη βεβαιότητα.
- **Κεφάλαιο:** Threats to validity
- **Θέματα:** confidence; calibration; OOD
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Τα δίκτυα μπορούν να αποδίδουν υψηλή predicted probability σε λάθος ή OOD inputs. Το score μπορεί να διαχωρίζει κατανομές σε aggregate επίπεδο, αλλά η τιμή του για ένα μεμονωμένο example δεν αποτελεί αξιόπιστη πιθανότητα ορθότητας.

### Συμφραζόμενα

Η διάκριση μεταξύ detection ranking και calibrated confidence είναι κεντρική στην εργασία.

### Περιορισμοί και κίνδυνος παρερμηνείας

Υψηλό AUROC δεν συνεπάγεται καλά calibrated probabilities ή επιτυχημένο near-OOD detection.

### Προτεινόμενη χρήση

Αποτροπή του λανθασμένου ισχυρισμού ότι softmax score ισούται με uncertainty estimate.

### Παραπομπή

Hendrycks and Gimpel (2016), Introduction and Tables 1–2, arXiv:1610.02136.
