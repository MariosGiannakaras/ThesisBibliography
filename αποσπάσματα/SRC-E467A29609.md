# Επαληθευμένα τεκμήρια — SRC-E467A29609

## 1. State entropy και policy entropy είναι διαφορετικοί μηχανισμοί
- **Τύπος:** πιστή παράφραση
- **Θέση:** Abstract, Introduction
- **Ισχυρισμός:** Η policy entropy ενθαρρύνει stochasticity των actions, ενώ η state entropy ενθαρρύνει ευρύτερη visitation distribution στο state space.
- **Κεφάλαιο:** Exploration / Robust baselines
- **Θέματα:** state entropy; policy entropy; coverage
- **Κατάσταση:** επαληθευμένο

### Προτεινόμενη χρήση
Να αναφέρονται χωριστά action entropy και state-visitation entropy.

## 2. Structured/spatial perturbations
- **Τύπος:** πιστή παράφραση
- **Θέση:** Abstract, Introduction, Section 5
- **Ισχυρισμός:** Η state-entropy regularization εμφανίζει ιδιαίτερο robustness benefit σε structured και spatially correlated perturbations, όπως obstacle placement που μπλοκάρει dominant trajectories.
- **Κεφάλαιο:** Perturbation taxonomy
- **Θέματα:** structured change; spatial perturbation; obstacle; coverage
- **Κατάσταση:** επαληθευμένο

### Προτεινόμενη χρήση
Tabular coverage ablation για wall/topology changes που καθιστούν εναλλακτικές διαδρομές κρίσιμες.

## 4. Entropy regularization έχει σαφή όρια
- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 4
- **Ισχυρισμός:** State/policy entropy regularization δεν λύνει γενικά kernel-robust RL και μπορεί να έχει arbitrarily κακή risk-averse performance σε ορισμένα settings.
- **Κεφάλαιο:** Threats to validity
- **Θέματα:** failure cases; kernel robustness; risk
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση
Υψηλή state coverage δεν αποτελεί γενική robustness ή resilience εγγύηση.

## 5. Rollout-budget sensitivity
- **Τύπος:** πιστή παράφραση
- **Θέση:** Abstract, Section 4.3, Section 5
- **Ισχυρισμός:** Τα robustness gains της state entropy είναι πιο ευαίσθητα στον αριθμό rollouts που χρησιμοποιούνται για policy evaluation.
- **Κεφάλαιο:** Experimental fairness
- **Θέματα:** rollout budget; evaluation; sample sensitivity
- **Κατάσταση:** επαληθευμένο

### Προτεινόμενη χρήση
Ο αριθμός evaluation rollouts είναι reportable budget και κρατείται κοινός μεταξύ comparators.
