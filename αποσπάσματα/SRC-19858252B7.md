# Τεκμήρια

## 1. Safety-transfer metrics
- Τύπος: πιστή παράφραση
- Θέση: Section 4.2, Figure 2
- Ισχυρισμός: Η safe-transfer αξιολόγηση διαχωρίζει safety jump-start και χρόνο μέχρι safety από return jump-start και χρόνο μέχρι optimal task performance.
- Κεφάλαιο: Μετρικές / Transfer
- Θέματα: safety jump-start; time to safety; return jump-start; time to optimum
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Όταν source knowledge μεταφέρεται σε target task, πρέπει να μετράται χωριστά πόσο ασφαλής είναι ο agent από την αρχή και πόσο γρήγορα γίνεται ασφαλής, καθώς και πόσο γρήγορα βελτιώνει task return.

### Συμφραζόμενα
Οι metrics συγκρίνουν transfer με learning from scratch.

### Περιορισμοί και κίνδυνος παρερμηνείας
Safety improvement δεν συνεπάγεται ταχύτερο task recovery και αντιστρόφως.

### Προτεινόμενη χρήση
Άμεση υιοθέτηση ως συμπληρωματικές metrics σε context recall/pretrained safety baselines.

### Παραπομπή
Yang et al., Section 4.2.

## 2. Source guide ως prior advantage
- Τύπος: πιστή παράφραση
- Θέση: Sections 1, 4
- Ισχυρισμός: Ο guide εκπαιδεύεται προηγουμένως σε controlled source environment και μεταφέρει safety knowledge στον target learner.
- Κεφάλαιο: Fair comparison / Threats to validity
- Θέματα: safe guide; source task; transfer; prior data
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Η καλύτερη αρχική safety του transfer agent προέρχεται από προηγούμενη source training και άρα δεν είναι δωρεάν capability.

### Συμφραζόμενα
Το source environment μπορεί να επιτρέπει unsafe interactions που δεν επιτρέπονται στο target.

### Περιορισμοί και κίνδυνος παρερμηνείας
Χωρίς accounting source interactions, σύγκριση με scratch learner είναι άνιση.

### Προτεινόμενη χρήση
Report `pretraining_interaction_budget`, `guide_use_fraction` και mismatch ablation.

### Παραπομπή
Yang et al., Sections 1, 4.
