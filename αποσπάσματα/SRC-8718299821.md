# Τεκμήρια

## 1. Shield ως ξεχωριστό correctness layer
- Τύπος: πιστή παράφραση
- Θέση: Abstract, Introduction
- Ισχυρισμός: Το shield επιβάλλει safety ανεξάρτητα από το πόσο γρήγορα ή καλά μαθαίνει ο RL agent.
- Κεφάλαιο: Safe RL / Agent architecture
- Θέματα: shielding; temporal logic; runtime assurance
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Η αρχιτεκτονική τοποθετεί ένα formal safety component μεταξύ learner και environment, ώστε η correctness guarantee να μην εξαρτάται από την convergence της learned policy.

### Συμφραζόμενα
Το shield χρειάζεται specification και abstraction του environment.

### Περιορισμοί και κίνδυνος παρερμηνείας
Η safety της executed behavior δεν πρέπει να αποδίδεται αποκλειστικά στη learned policy.

### Προτεινόμενη χρήση
Να αναφέρονται proposed και executed actions και intervention rate.

### Παραπομπή
Alshiekh et al., arXiv:1708.08611.

## 2. Preemptive και post-posed shielding
- Τύπος: πιστή παράφραση
- Θέση: Introduction, Figures 1–2
- Ισχυρισμός: Preemptive shielding παρέχει σύνολο safe actions πριν την επιλογή, ενώ post-posed shielding διορθώνει unsafe action που ήδη πρότεινε ο learner.
- Κεφάλαιο: Experimental protocol
- Θέματα: action masking; override; intervention
- Κατάσταση: επαληθευμένο

### Κείμενο ή πιστή παράφραση
Οι δύο αρχιτεκτονικές αλλάζουν διαφορετικά το information/action interface του learner και συνεπώς δεν πρέπει να θεωρούνται ισοδύναμες baselines.

### Συμφραζόμενα
Και οι δύο στοχεύουν minimum interference.

### Περιορισμοί και κίνδυνος παρερμηνείας
Το action masking μπορεί να διευκολύνει το learning επιπλέον της safety, άρα αποτελεί capability advantage.

### Προτεινόμενη χρήση
Report `shield_mode`, override fraction και available-action reduction.

### Παραπομπή
Alshiekh et al., Introduction.
