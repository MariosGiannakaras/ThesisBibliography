# SRC-9D663D35D0 — Χρήσιμα αποσπάσματα

## 1. Γιατί model-free robust MDP

**Τεκμήριο:** Η εργασία επισημαίνει ότι πολλά robust-MDP methods απαιτούν explicit transition estimation με αποθηκευτικό κόστος τάξης `O(|S|²|A|)` και συχνά έναν ισχυρό oracle για το εσωτερικό DRO πρόβλημα.

**Ασφαλής χρήση:** «Η robust-MDP βιβλιογραφία δεν είναι κατ’ ανάγκη πρακτικά model-free· ορισμένες μέθοδοι απαιτούν πλήρες transition model ή oracle επίλυσης του inner robust problem.»

## 2. Penalized robust formulation

**Τεκμήριο:** Οι συγγραφείς μετατρέπουν το constrained robust MDP σε penalized formulation μέσω Lagrangian duality ώστε το dual DRO objective να μπορεί να αντιμετωπιστεί με stochastic-gradient methods.

**Ασφαλής χρήση:** «Μία εναλλακτική robust διατύπωση μπορεί να ανταλλάξει explicit constraints για penalty term, διευκολύνοντας sample-based optimization χωρίς ακριβές robust oracle.»

## 3. Χωρίς explicit model estimation

**Τεκμήριο:** Προτείνονται Q-learning-type αλγόριθμοι με storage `O(|S||A|)` και finite-sample guarantees.

**Ασφαλής χρήση:** «Υπάρχουν robust Q-learning formulations που δεν απαιτούν αποθήκευση πλήρους transition tensor, γεγονός που τις καθιστά καταλληλότερες ως resource-aware tabular comparators.»

## 4. Δύο data-access regimes

**Τεκμήριο:** Η εργασία αναλύει τόσο generative-model sampling όσο και Markovian data από μία trajectory υπό behavior policy.

**Ασφαλής χρήση:** «Το sample-access model αποτελεί ουσιώδες μέρος της σύγκρισης: generative-model access και single-trajectory online learning δεν έχουν το ίδιο πληροφοριακό budget.»

## 5. Όριο ως προς resilience

**Τεκμήριο:** Η μέθοδος βελτιστοποιεί έναν worst-case objective γύρω από uncertainty formulation· δεν περιλαμβάνει changepoint detector, regime memory ή explicit recovery mechanism.

**Ασφαλής χρήση:** «Model-free robust optimization δεν ισοδυναμεί με online resilience μετά από άγνωστη απότομη αλλαγή.»

## 6. Μετρικές για τη διπλωματική

Να αναφέρονται μαζί:

- clean return,
- disturbed/in-set return,
- out-of-set structural-shift return,
- conservativeness gap,
- interaction count,
- generative-model query count όπου υπάρχει,
- memory footprint,
- update-time overhead.

## Αποφυγή υπερ-ισχυρισμού

Δεν χρησιμοποιείται η πηγή για να υποστηριχθεί ότι:

- η robust Q-learning ανιχνεύει αλλαγές,
- προσαρμόζεται ταχύτερα από recency ή reset baselines,
- είναι ανθεκτική σε arbitrary out-of-support αλλαγές.
