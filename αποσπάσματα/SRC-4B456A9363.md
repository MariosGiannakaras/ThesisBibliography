# Αποσπάσματα — Non-stationary Reinforcement Learning under General Function Approximation

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** Abstract και Introduction, PDF σελ. 1–2
- **Ισχυρισμός:** Sliding-window learning περιορίζει το mismatch μεταξύ παλιών samples και του τρέχοντος MDP.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο· Adaptive baselines
- **Θέματα:** sliding window; stale data; distribution mismatch
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Ο SW-OPEA κατασκευάζει confidence region από πρόσφατα episodes και ενσωματώνει local variation, ώστε η τρέχουσα optimal value function να παραμένει μέσα στο confidence set παρά τις μεταβολές rewards και transitions.

### Συμφραζόμενα

Η εργασία αφορά general function approximation και confidence-set based model-free RL.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η θεωρητική κατασκευή είναι πολύ πιο σύνθετη από μια απλή tabular finite-window baseline.

### Προτεινόμενη χρήση

Αιτιολόγηση περιορισμένης recent memory μετά από environmental change.

### Παραπομπή

Feng et al., 2023, Abstract και §1, PDF σελ. 1–2.

## Τεκμήριο E2

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 1.1, PDF σελ. 2–3
- **Ισχυρισμός:** Sliding window, restart και exponential weighting είναι διακριτές families αντιμετώπισης non-stationarity.
- **Κεφάλαιο:** Σχετικές εργασίες· Agent taxonomy
- **Θέματα:** restart; discounting; recency weighting
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Η σχετική βιβλιογραφία χρησιμοποιεί sliding windows για tabular MDPs, restart του base learner για accumulated change και exponentially weighted least squares για βαθμιαία υποβάθμιση της επιρροής παλιών δεδομένων.

### Συμφραζόμενα

Οι μηχανισμοί εμφανίζονται σε διαφορετικές structural assumptions και regret analyses.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η αναφορά τους δεν αποδεικνύει ότι είναι ισοδύναμοι ή ότι ένας υπερέχει σε όλα τα scenarios.

### Προτεινόμενη χρήση

Ορισμός χωριστών baselines: hard reset, finite window και exponential recency.

### Παραπομπή

Feng et al., 2023, §1.1, PDF σελ. 2–3.

### Συμφραζόμενα

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν προκύπτει universal window length για το GridWorld της διπλωματικής.

## Τεκμήριο E4

- **Τύπος:** πιστή παράφραση
- **Θέση:** Discussion μετά το Corollary 5.3, PDF σελ. 6–7
- **Ισχυρισμός:** Το dynamic regret περιλαμβάνει χωριστό stationary και non-stationarity κόστος.
- **Κεφάλαιο:** Μετρικές
- **Θέματα:** dynamic regret; stationary cost; adaptation cost
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Ένας όρος του bound αντιστοιχεί στο regret του στατικού MDP, ενώ οι υπόλοιποι όροι προκύπτουν από μεταβολές transitions και rewards.

### Συμφραζόμενα

Η decomposition είναι θεωρητική και εκφράζεται σε cumulative regret.

### Περιορισμοί και κίνδυνος παρερμηνείας

Στη διπλωματική η decomposition θα προσεγγιστεί με clean performance, immediate degradation, recovery deficit και adaptation overhead, όχι με αυτούσια αναπαραγωγή του theorem.

### Προτεινόμενη χρήση

Αιτιολόγηση χωριστής αναφοράς nominal learning και post-change recovery cost.

### Παραπομπή

Feng et al., 2023, §5, PDF σελ. 6–7.

## Τεκμήριο E5

- **Τύπος:** πιστή παράφραση
- **Θέση:** Sections 5–6, PDF σελ. 7–9
- **Ισχυρισμός:** Το θεωρητικό πλεονέκτημα του SW-OPEA περιορίζεται κυρίως σε small-variation regimes.
- **Κεφάλαιο:** Threats to validity
- **Θέματα:** small variation; theoretical comparison; scope
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Σε linear και tabular special cases, το bound βελτιώνει ορισμένες dependencies αλλά είναι χειρότερο ως προς average transition variation, άρα η προτεινόμενη μέθοδος είναι κυρίως ελκυστική όταν η variation είναι μικρή.

### Συμφραζόμενα

Η σύγκριση αφορά regret upper bounds και όχι measured returns σε κοινό benchmark.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν επιτρέπεται να παρουσιαστεί ως empirical superiority του SW-OPEA.

### Προτεινόμενη χρήση

Οριοθέτηση: recent-window baseline για gradual ή moderate change, με ξεχωριστό hard-reset baseline για severe abrupt change.

### Παραπομπή

Feng et al., 2023, §§5–6, PDF σελ. 7–9.
