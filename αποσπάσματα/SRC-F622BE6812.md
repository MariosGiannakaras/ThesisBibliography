## SRC-F622BE6812 — Exploration by Random Network Distillation

- **Ρόλος:** υποστηρικτική
- **Κατάσταση:** επαληθευμένη

### Citation-ready τεκμήρια

1. **Η RND χρησιμοποιεί prediction error ως intrinsic reward.** Ένα trainable predictor μιμείται τα features ενός σταθερού τυχαίου target network και σφάλμα σε λιγότερο οικείες observations λειτουργεί ως novelty bonus.

2. **Το deterministic target μειώνει το noisy-TV πρόβλημα** σε σχέση με forward-dynamics prediction, επειδή το prediction target δεν είναι στοχαστικό ως συνάρτηση της observation.

3. **Prediction error δεν ισοδυναμεί με calibrated uncertainty ή change detection.** Επηρεάζεται από visitation frequency, model capacity, optimization, normalization και representation mismatch.

4. **Η intrinsic reward είναι εγγενώς μη στάσιμη**, καθώς μειώνεται όταν ο predictor εκπαιδεύεται στις ήδη παρατηρημένες καταστάσεις.

5. **Intrinsic και extrinsic returns πρέπει να αναφέρονται χωριστά.** Η αύξηση novelty/exploration δεν αποδεικνύει βελτίωση task utility ή ασφαλή προσαρμογή.

### Χρήση στη διπλωματική

- Directed-exploration reference μετά από detected shift.
- Diagnostic για novelty και state coverage.
- Caveat ότι prediction error δεν αποτελεί από μόνο του regime detector.
- Προτιμητέα tabular approximation με counts/bonus πριν από πλήρη deep RND.
