# Αποσπάσματα — Non-stationary Reinforcement Learning without Prior Knowledge: An Optimal Black-box Approach

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** Abstract και Introduction, PDF σελ. 1–3
- **Ισχυρισμός:** Η γνώση του αριθμού ή της έντασης αλλαγών αποτελεί σημαντικό oracle advantage σε non-stationary RL.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο· Experimental protocol
- **Θέματα:** prior knowledge; number of changes; variation budget
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Πολλοί προηγούμενοι non-stationary algorithms απαιτούν εκ των προτέρων γνώση του πόσες αλλαγές θα συμβούν ή πόσο θα μεταβληθεί συνολικά το περιβάλλον, πληροφορία που συχνά δεν είναι διαθέσιμη στην πράξη.

### Συμφραζόμενα

Η εργασία χρησιμοποιεί `L` για τον αριθμό αλλαγών και `Δ` για τη συνολική variation.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η απουσία αυτής της γνώσης δεν σημαίνει ότι κάθε fixed baseline είναι άχρηστο· σημαίνει ότι πρέπει να σημειώνεται ως oracle ή development-tuned.

### Προτεινόμενη χρήση

Διάκριση oracle periodic reset από deployable detector-triggered reset.

### Παραπομπή

Wei & Luo, 2021, Abstract και §1, PDF σελ. 1–3.
