# SRC-52E62452B8 — verified excerpts

## Robust-MDP motivation

Η εργασία δείχνει ότι οι optimal MDP policies μπορεί να είναι πολύ ευαίσθητες σε estimation errors των transition probabilities. Αυτό αιτιολογεί robust optimization όταν το transition model είναι αβέβαιο.

**Χρήση στη διπλωματική:** θεωρητική αιτιολόγηση robust baseline απέναντι σε transition-model uncertainty.

## Rectangular uncertainty και robust dynamic programming

Υπό rectangular uncertainty structure, το minimax robust-control πρόβλημα επιλύεται με robust dynamic-programming recursion. Η nature επιλέγει worst-case next-state distribution μέσα στο αντίστοιχο uncertainty set.

**Ασφαλής παράφραση:** Η robust Bellman recursion αντικαθιστά το nominal expectation με worst-case expectation μέσα σε προκαθορισμένο set πιθανών transition distributions.

## Stationary έναντι time-varying uncertainty

Η εργασία διαχωρίζει uncertainty όπου το άγνωστο transition model παραμένει σταθερό από ισχυρότερο formulation όπου το model μπορεί να μεταβάλλεται χρονικά μέσα στα bounds.

**Χρήση:** να μη συγχέεται αυτόματα time-varying robust uncertainty με piecewise-stationary changepoints και online adaptation.

## Uncertainty-set quality

Οι συγγραφείς επισημαίνουν ότι γενικά polytopic/interval sets μπορεί να είναι φτωχή στατιστική αναπαράσταση της uncertainty και να οδηγήσουν σε overly conservative policies. Προτείνουν likelihood/entropy-based sets ως πιο meaningful περιπτώσεις.

**Protocol implication:** καταγραφή set family, radius και τρόπου calibration μαζί με clean-performance loss.

## Robustness ≠ resilience

Η εργασία δεν προτείνει changepoint detector ή continual adaptation. Η policy βελτιστοποιείται ώστε να έχει καλή worst-case performance εντός ενός uncertainty model.

**Μη επιτρεπτός ισχυρισμός:** ότι robust dynamic programming αποτελεί απόδειξη ταχύτερης recovery μετά από abrupt environmental change.

## Thesis-ready claims

- Robustness σε model uncertainty απαιτεί explicit uncertainty set.
- Η επιλογή του uncertainty set επηρεάζει άμεσα conservativeness και computational tractability.
- In-set worst-case robustness πρέπει να αξιολογείται χωριστά από out-of-set structural changes.
- Static robust policy και adaptive post-change policy είναι διαφορετικές κατηγορίες agents.
