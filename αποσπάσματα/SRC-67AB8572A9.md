# Επαληθευμένα τεκμήρια — SRC-67AB8572A9

## 1. Continual learning ως ειδική περίπτωση transfer

**Τεκμήριο:** Η εργασία περιγράφει το continual learning ως πιο απαιτητική περίπτωση transfer, όπου οι tasks εμφανίζονται διαδοχικά και δεν είναι απαραίτητα γνωστές εκ των προτέρων.

**Παράφραση για χρήση:** Η online προσαρμογή σε ακολουθία regimes δεν πρέπει να παρουσιάζεται απλώς ως static source-to-target transfer.

**Χρήση:** Ορισμοί και agent taxonomy.

## 2. Task detection και forgetting

**Τεκμήριο:** Automatic task detection και αποφυγή catastrophic forgetting θεωρούνται βασικές απαιτήσεις continual learning.

**Παράφραση για χρήση:** Ένας context-library agent χρειάζεται τόσο αξιόπιστη αναγνώριση regime όσο και διατήρηση προηγούμενης γνώσης.

**Χρήση:** Context recall protocol.

## 3. Negative transfer

**Τεκμήριο:** Η κοινή χρήση γνώσης μεταξύ άσχετων ή συγκρουόμενων tasks μπορεί να μειώσει την επίδοση αντί να τη βελτιώσει.

**Παράφραση για χρήση:** Κάθε transfer ή recall mechanism πρέπει να συγκρίνεται με no-transfer baseline, ώστε να εντοπίζεται αρνητική μεταφορά.

**Χρήση:** Baselines και threats to validity.

## 4. Mastery και generalization/adaptation speed

**Τεκμήριο:** Η αξιολόγηση transfer περιλαμβάνει τόσο την τελική επίδοση στον target domain όσο και την ταχύτητα με την οποία ο agent προσαρμόζεται.

**Παράφραση για χρήση:** Final return και time-to-recovery αποτυπώνουν διαφορετικές ιδιότητες και δεν πρέπει να συγχωνεύονται.

**Χρήση:** Metrics.

## 5. Διαφορετικές μορφές μεταφερόμενης γνώσης

**Τεκμήριο:** Transfer μπορεί να αφορά policies, representations, demonstrations, reward shaping ή mappings μεταξύ tasks.

**Παράφραση για χρήση:** Context recall, representation transfer και reward shaping είναι διαφορετικοί mechanisms και απαιτούν χωριστή περιγραφή και ablation.

**Χρήση:** Agent classification.

## 6. Όριο μεταφοράς

**Τεκμήριο:** Η εργασία είναι survey και οι κατηγορίες της καλύπτουν κυρίως deep-RL approaches.

**Παράφραση για χρήση:** Χρησιμοποιείται για taxonomy και evaluation dimensions, όχι ως empirical απόδειξη υπεροχής context recall σε tabular GridWorld.

**Χρήση:** Περιορισμοί.
