# Αποσπάσματα — CARL

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 2, pp. 2–3
- **Ισχυρισμός:** Ένα contextual MDP οργανώνει πολλαπλά instances του ίδιου task με κοινό state/action interface και context-dependent transition ή reward functions.
- **Κεφάλαιο:** Θεωρητικό υπόβαθρο
- **Θέματα:** contextual MDP; environment family; task instance
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το CARL θεωρεί μία οικογένεια MDPs όπου κάθε instance δειγματοληπτείται από distribution και ορίζεται από context. Τα instances διατηρούν κοινά state και action spaces, αλλά μπορούν να διαφέρουν στις transition dynamics, στη reward function και στο υποσύνολο reachable states.

### Συμφραζόμενα

Το formalism επιτρέπει να οριστούν generalization, transfer και curriculum objectives πάνω σε σαφή train/test instance sets.

### Περιορισμοί και κίνδυνος παρερμηνείας

Το κοινό interface δεν σημαίνει ίδια difficulty ή ίδια optimal policy μεταξύ instances.

### Προτεινόμενη χρήση

Ορισμός των GridWorld configurations ως context-resolved MDP instances.

### Παραπομπή

Benjamins et al., Section 2, pp. 2–3.

## Τεκμήριο E2

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 4, p. 5
- **Ισχυρισμός:** Η explicit/implicit context διάκριση αποτρέπει τη σύγχυση policy generalization με representation learning.
- **Κεφάλαιο:** Μεθοδολογία· Threats to validity
- **Θέματα:** explicit context; hidden context; representation learning
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Explicit context είναι πληροφορία που παρέχεται άμεσα στον agent και μπορεί να χρησιμοποιηθεί για inference των dynamics. Implicit context είναι ενσωματωμένο στην παρατήρηση και πρέπει πρώτα να εξαχθεί, οπότε η αξιολόγηση συνδυάζει representation learning και policy generalization.

### Συμφραζόμενα

Το CARL επιτρέπει context-visible και context-hidden variants του ίδιου benchmark.

### Περιορισμοί και κίνδυνος παρερμηνείας

Οι δύο variants δίνουν διαφορετικό information set στον agent και δεν είναι απλή αλλαγή hyperparameter.

### Προτεινόμενη χρήση

Καθαρή δήλωση του αν ο agent γνωρίζει το change/context variable σε κάθε experimental condition.

### Παραπομπή

Benjamins et al., Section 4, p. 5.

## Τεκμήριο E3

- **Τύπος:** πιστή παράφραση
- **Θέση:** Sections 1 και 5, pp. 2 και 6
- **Ισχυρισμός:** Ρητά bounds και sampling distributions για context variables είναι προϋπόθεση συγκρίσιμης και αναπαραγώγιμης generalization evaluation.
- **Κεφάλαιο:** Πειραματικό πρωτόκολλο
- **Θέματα:** train distribution; test distribution; reproducibility; context bounds
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το benchmark αποφεύγει ad hoc μεταβολές ορίζοντας επιτρεπτά ranges και distributions για κάθε context. Έτσι οι train και test instance populations μπορούν να ανακατασκευαστούν και η απόσταση ενός test case από την train distribution να δηλωθεί ρητά.

### Συμφραζόμενα

Οι context features επηρεάζουν κυρίως transition dynamics και σε μικρότερο βαθμό rewards.

### Περιορισμοί και κίνδυνος παρερμηνείας

Το ότι ένα range είναι reproducible δεν σημαίνει ότι είναι επιστημονικά κατάλληλο· η επιλογή severity χρειάζεται αιτιολόγηση.

### Προτεινόμενη χρήση

Αποθήκευση resolved context values και generation distributions σε κάθε run.

### Παραπομπή

Benjamins et al., Sections 1 και 5, pp. 2 και 6.

## Τεκμήριο E4

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 6, p. 7
- **Ισχυρισμός:** Τα κύρια CARL experiments χρησιμοποιούν πολλαπλά seeds και context samples και παρέχουν reproduction scripts.
- **Κεφάλαιο:** Αναπαραγωγιμότητα
- **Θέματα:** random seeds; context sampling; experiment scripts
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Για τα κύρια experiments οι authors αναφέρουν training/evaluation σε πέντε random seeds και 100 sampled contexts, μαζί με hyperparameter/hardware details και scripts αναπαραγωγής.

### Συμφραζόμενα

Το protocol εφαρμόζεται σε demonstrations που μελετούν context variation, visibility και ID/OOD transfer.

### Περιορισμοί και κίνδυνος παρερμηνείας

Ο αριθμός πέντε seeds δεν μεταφέρεται μηχανικά στη διπλωματική· ο τελικός αριθμός πρέπει να προκύψει από variance και compute pilots.

### Προτεινόμενη χρήση

Παράδειγμα για το γιατί generalization claims χρειάζονται πολλαπλά seeds και πολλά environment instances.

### Παραπομπή

Benjamins et al., Section 6, p. 7.

## Τεκμήριο E5

- **Τύπος:** πιστή παράφραση
- **Θέση:** Sections 6.1–6.3 και Figure 6, pp. 7–9
- **Ισχυρισμός:** Μεγαλύτερη context variation δυσκολεύει τη μάθηση και καλή ID επίδοση δεν εγγυάται OOD generalization.
- **Κεφάλαιο:** Αποτελέσματα· Threats to validity
- **Θέματα:** context severity; ID; OOD; crashes
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Στο Pendulum, ισχυρότερη μεταβολή μεμονωμένων dynamics features κάνει τη μάθηση δυσκολότερη και η explicit context πληροφορία συχνά βοηθά. Στο LunarLander scenario, οι agents έχουν καλύτερη συμπεριφορά κοντά στην train gravity distribution, ενώ η επίδοση και η συχνότητα επιτυχημένης προσγείωσης υποβαθμίζονται σε πιο απομακρυσμένα OOD planets.

### Συμφραζόμενα

Τα αποτελέσματα αφορούν συγκεκριμένους DDPG/DQN agents και context distributions.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν αποδεικνύεται καθολική αποτυχία OOD generalization ούτε καθολική υπεροχή visible context.

### Προτεινόμενη χρήση

Αιτιολόγηση χωριστών ID, near-OOD και far-OOD severity bands.

### Παραπομπή

Benjamins et al., Sections 6.1–6.3 και Figure 6, pp. 7–9.

## Τεκμήριο E6

- **Τύπος:** πιστή παράφραση
- **Θέση:** Section 8, pp. 9–10
- **Ισχυρισμός:** Τα reported CARL experiments περιορίζονται σε static contexts και δεν αξιολογούν continual adaptation σε dynamic contexts.
- **Κεφάλαιο:** Threats to validity
- **Θέματα:** static context; dynamic context; continual learning
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Οι authors δηλώνουν ότι τα experiments χρησιμοποιούν στατικά contexts και συνήθως μεταβάλλουν ένα context feature κάθε φορά. Dynamic contexts, continual learning και richer vision-based context exposure αφήνονται για μελλοντική εργασία.

### Συμφραζόμενα

Το CARL προσφέρει υποδομή που θα μπορούσε να χρησιμοποιηθεί για continual evaluation, αλλά η συγκεκριμένη εργασία δεν παρέχει τέτοια empirical validation.

### Περιορισμοί και κίνδυνος παρερμηνείας

Η δυνατότητα του framework δεν πρέπει να παρουσιάζεται ως ήδη αποδεδειγμένο dynamic-resilience result.

### Προτεινόμενη χρήση

Ρητός διαχωρισμός static generalization tests από changepoint/recovery tests της διπλωματικής.

### Παραπομπή

Benjamins et al., Section 8, pp. 9–10.
