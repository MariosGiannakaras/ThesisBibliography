# Αποσπάσματα — Context-Switching and Adaptation

## Τεκμήριο E1

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδες 1–2, Introduction και Figure 1
- **Ισχυρισμός:** Μετά από αλλαγή transition contingencies, οι παλιές value estimates και το παλιό model μπορούν να εμποδίζουν την εύρεση νέας λύσης αντί απλώς να είναι ανεπαρκή.
- **Κεφάλαιο:** Non-stationarity και motivation
- **Θέματα:** stale model, changing transitions, negative transfer, relearning
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Ένας model-based agent που έχει μάθει το πρώτο maze διατηρεί πληροφορία για τα παλιά walls και τις παλιές transition probabilities. Όταν μεταφερθεί σε δεύτερο maze, το planning model μπορεί να συμπεράνει λανθασμένα ότι δεν υπάρχει route προς τον goal. Η νέα σωστή διαδρομή θα ανακαλυφθεί μόνο όταν exploration παράγει transitions που αναιρούν το παλιό μοντέλο. Συνεπώς, η παλιά γνώση μπορεί να προκαλέσει αρνητική μεταφορά και βαθύτερη post-change υποβάθμιση.

### Συμφραζόμενα

Το παράδειγμα είναι deterministic spatial navigation και δεν καλύπτει κάθε μορφή non-stationarity. Δείχνει όμως γιατί η συνέχιση learning με παλιά estimates δεν εγγυάται γρήγορη adaptation.

### Περιορισμοί και κίνδυνος παρερμηνείας

Δεν πρέπει να συμπεράνουμε ότι model-free agents προσαρμόζονται πάντα καλύτερα. Η συμπεριφορά εξαρτάται από replay, forgetting, exploration και learning rates.

### Προτεινόμενη χρήση

Να αιτιολογήσει μέτρηση negative transfer και σύγκριση warm-start, reset και context-aware adaptation baselines.

### Παραπομπή

Chalmers et al. (2016), σελ. 1–2, Introduction και Figure 1.

## Τεκμήριο E2

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδες 4–6, Sections II.B–II.C και Figure 5
- **Ισχυρισμός:** Ένα non-stationary agent χρειάζεται χωριστή διαδικασία αναγνώρισης context και χωριστή διαδικασία επιλογής recall, adaptation ή new-model learning.
- **Κεφάλαιο:** Agent architecture και change handling
- **Θέματα:** context detection, model library, recall, adaptation, relearning
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το σύστημα διατηρεί recent transition history και υπολογίζει πόσο πιθανό είναι αυτό υπό το current model. Όταν η πιθανότητα πέσει κάτω από threshold, θεωρεί ότι το περιβάλλον άλλαξε. Στη συνέχεια ελέγχει τη library αποθηκευμένων models: αν κάποιο εξηγεί τα νέα δεδομένα, το ανακαλεί· διαφορετικά προσπαθεί να προσαρμόσει το πιο σχετικό model και, αν αυτό αποτύχει, δημιουργεί νέο.

### Συμφραζόμενα

Η ανίχνευση βασίζεται σε transition likelihood, όχι σε return alone. Η αρχιτεκτονική προϋποθέτει ότι διαφορετικά contexts μπορούν να αναπαρασταθούν με διακριτά models.

### Περιορισμοί και κίνδυνος παρερμηνείας

Threshold και history length είναι hyperparameters. Τυχαία early transitions μπορούν να οδηγήσουν σε λάθος context ή duplicate model. Η library approach δεν είναι κατάλληλη χωρίς bounded number of recurring regimes.

### Προτεινόμενη χρήση

Να ορίσει τρεις κατηγορίες adaptation outcome και telemetry για detected context, selected model και model-creation events.

### Παραπομπή

Chalmers et al. (2016), σελ. 4–6, Sections II.B–II.C και Figure 5.

## Τεκμήριο E3

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδα 6, Section III
- **Ισχυρισμός:** Ένα repeated-context benchmark μπορεί να συγκρίνει first-time adaptation, retention και recall με ελεγχόμενο compute budget και πολλές repetitions.
- **Κεφάλαιο:** Πειραματικό πρωτόκολλο
- **Θέματα:** repeated environments, GridWorld sequence, repetitions, compute fairness
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Οι συγγραφείς χρησιμοποιούν οκτώ GridWorld environments 16×48. Ο agent παραμένει δέκα trials σε κάθε environment και μετά μεταφέρεται στο επόμενο. Η πλήρης sequence επαναλαμβάνεται δύο φορές, άρα η δεύτερη έκθεση επιτρέπει έλεγχο model recall. Κάθε trial τελειώνει στον goal ή στις 5.000 steps, τα tests επαναλαμβάνονται 200 φορές και οι learning systems λαμβάνουν συγκρίσιμο συνολικό αριθμό model updates ανά step.

### Συμφραζόμενα

Το protocol είναι σχεδιασμένο για model-based agents με library. Ωστόσο, η διάκριση novel versus recurring context είναι γενική και μπορεί να εφαρμοστεί σε άλλους agents.

### Περιορισμοί και κίνδυνος παρερμηνείας

Τα 16×48 grids και οι 200 repetitions δεν είναι υποχρεωτικές τιμές. Η διπλωματική πρέπει να επιλέξει μικρότερο scalable design βάσει compute budget και power/uncertainty analysis.

### Προτεινόμενη χρήση

Να εισαχθεί sequence A→B→C→A ή randomized recurring regimes, με separate metrics για πρώτη και επόμενη εμφάνιση.

### Παραπομπή

Chalmers et al. (2016), σελ. 6, Section III.

## Τεκμήριο E4

- **Τύπος:** πιστή παράφραση
- **Θέση:** σελίδες 6–7, Section IV, Figures 7–9 και Discussion
- **Ισχυρισμός:** Η γρήγορη recovery σε recurring context μπορεί να προκύπτει από recall, ενώ η recovery σε νέο related context μπορεί να προκύπτει από adaptation· οι δύο περιπτώσεις δεν πρέπει να συγχέονται.
- **Κεφάλαιο:** Αποτελέσματα και μετρικές adaptation
- **Θέματα:** recovery, recall, transfer, context reuse, negative transfer
- **Κατάσταση:** επαληθευμένο

### Κείμενο ή πιστή παράφραση

Το context-switching system επαναφέρει λύσεις στη δεύτερη έκθεση των environments, ενώ η hierarchy επιταχύνει ορισμένες πρώτες εκθέσεις όταν υπάρχει model που μπορεί να προσαρμοστεί. Προηγούμενη έκθεση σε environment A βοηθά στο E, επειδή το A αποτελεί κατάλληλο starting model, ενώ το B δεν είναι. Σε άλλο case, environment G λύνεται με συνδυασμό γνώσης από B και E. Η conventional model-based baseline δυσκολεύεται επειδή οι παλιές transitions παραμένουν στο model.

### Συμφραζόμενα

Το αποτέλεσμα αποδεικνύει benefit στο συγκεκριμένο sequence, όχι καθολική compositional generalization. Οι Figures αναφέρουν median cumulative reward και interquartile error bars.

### Περιορισμοί και κίνδυνος παρερμηνείας

Recall παλιού policy/model δεν είναι ίδια ικανότητα με adaptation σε unseen dynamics. Οι τελικές αναφορές πρέπει να διαχωρίζουν recurring-regime recovery από novel-regime recovery.

### Προτεινόμενη χρήση

Να οριστούν retention/recall gain, first-exposure adaptation cost και second-exposure recovery time ως διαφορετικές μετρικές.

### Παραπομπή

Chalmers et al. (2016), σελ. 6–7, Section IV, Figures 7–9 και Discussion.
