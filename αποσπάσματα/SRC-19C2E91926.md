# SRC-19C2E91926 — Χρήσιμα αποσπάσματα

## 1. OOD detection ειδικά σε RL

**Τεκμήριο:** Η εργασία επισημαίνει ότι τα περισσότερα OOD benchmarks προέρχονται από supervised classification και προτείνει benchmark ειδικά για reinforcement-learning policies.

**Ασφαλής χρήση:** «Η OOD αξιολόγηση για RL χρειάζεται environment-level perturbations και όχι μόνο static image-classification anomalies.»

## 2. Dynamics shift έναντι observation corruption

**Τεκμήριο:** Τα OOD variants δημιουργούνται είτε με αλλαγές φυσικών/environment parameters είτε με corruption των observations.

**Ασφαλής χρήση:** «Αλλαγή dynamics και corruption της observation channel πρέπει να θεωρούνται διαφορετικές κατηγορίες perturbation και να αναφέρονται χωριστά.»

## 3. Severity-controlled perturbations

**Τεκμήριο:** Οι environment parameters και τα corruption levels μεταβάλλονται σε πολλαπλές κλίμακες.

**Ασφαλής χρήση:** «Η ανθεκτικότητα detector δεν πρέπει να αξιολογείται μόνο σε binary clean-vs-OOD setup αλλά και ως συνάρτηση severity.»

## 4. Uncertainty methods

**Τεκμήριο:** Η εργασία συγκρίνει MC Dropout, MC DropConnect και ensembles· στα συγκεκριμένα experiments τα ensembles έχουν την καλύτερη OOD-detection performance και χαμηλότερη διακύμανση μεταξύ environments.

**Ασφαλής χρήση:** «Στο συγκεκριμένο benchmark, ensembles υπερείχαν των εξεταζόμενων neural uncertainty baselines.»

**Μη ασφαλής γενίκευση:** Δεν δηλώνεται ότι ensembles είναι καθολικά ο καλύτερος detector για tabular RL ή sequential changepoints.

## 5. Static OOD score ≠ online changepoint detector

**Τεκμήριο:** Το paper αξιολογεί OOD detection σε perturbed environments αλλά δεν αποτελεί μελέτη detection delay/false alarms σε online piecewise-stationary sequence.

**Ασφαλής χρήση:** «Ένα καλό static OOD score δεν αρκεί για να τεκμηριώσει online change detection.»

## 6. Thesis-specific metrics

Η πηγή υποστηρίζει να χρησιμοποιηθούν μαζί με τα υπάρχοντα sequential metrics:

- AUROC/AUPR ή F1,
- severity-conditioned detector performance,
- score distributions clean/shifted,
- false-alarm rate,
- detection delay,
- missed-change rate,
- threshold-calibration protocol.

## Αποφυγή υπερ-ισχυρισμού

Δεν χρησιμοποιείται η πηγή για να υποστηριχθεί ότι:

- OOD detection συνεπάγεται adaptation,
- οι perturbations του benchmark είναι αντιπροσωπευτικές όλων των πραγματικών αλλαγών,
- neural ensembles πρέπει να μπουν υποχρεωτικά στο core implementation.
