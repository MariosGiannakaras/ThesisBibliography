# Πρωτότυπα αρχεία

Εδώ αποθηκεύονται τα αρχικά PDF που αντιστοιχούν στις πηγές. Δεν χρησιμοποιούνται ως έτοιμες παραπομπές χωρίς έλεγχο.

- Ταυτοποιημένο κύριο πρωτότυπο: `SRC-XXXXXXXXXX.pdf`
- Διαφορετική έκδοση της ίδιας πηγής: `SRC-XXXXXXXXXX__alternative-<hash>.pdf`
- PDF χωρίς ασφαλή αντιστοίχιση: `unidentified/<hash>__<αρχικό-όνομα>.pdf`

Κανένα PDF δεν διαγράφεται επειδή δεν έχει ακόμη μετατραπεί σε Markdown ή δεν έχει ταυτοποιηθεί. Διαγράφεται μόνο byte-for-byte ακριβές αντίγραφο, με ίδιο SHA-256 ή ισοδύναμο Git LFS object ID.

Τα κύρια ταυτοποιημένα PDF μετατρέπονται αυτόματα σε `sources/SRC-XXXXXXXXXX.md`. Η μετατροπή χρησιμοποιεί προσωρινό OCR αντίγραφο και δεν αλλάζει το αρχειακό PDF. Η τεχνική ποιότητα και η ανάγκη περαιτέρω μετατροπής καταγράφονται στα `catalog/conversion-status.md` και `.csv`.
