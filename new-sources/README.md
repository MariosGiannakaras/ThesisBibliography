# Νέες πηγές

Ανέβασε εδώ οποιονδήποτε φάκελο με αρχεία Markdown, προαιρετικά PDF, και προσωρινά αρχεία ελέγχου του NotebookLM. Δεν απαιτείται συγκεκριμένη εσωτερική δομή ούτε συγκεκριμένη ονομασία των εισερχόμενων αρχείων.

Το `new-sources/` και το `new-originals/` αποτελούν τις δύο εισόδους της **ίδιας canonical intake διαδικασίας**. Αν προστεθούν αρχεία και στους δύο φακέλους στο ίδιο commit, επεξεργάζονται από ένα workflow και ένα generated Pull Request· δεν ξεκινούν ανταγωνιστικές διαδικασίες εγγραφής.

Η intake διαδικασία:

1. εισάγει και απο-διπλοποιεί τις νέες πηγές,
2. διατηρεί τα πρωτότυπα PDF και αφαιρεί μόνο ακριβή αντίγραφα,
3. αντιστοιχίζει ή αρχειοθετεί με ασφάλεια νέα πρωτότυπα,
4. εκτελεί OCR/μετατροπή όπου χρειάζεται χωρίς να τροποποιεί το αρχικό PDF,
5. ενημερώνει metadata και catalog,
6. εκτελεί ολόκληρο το test/validation suite,
7. ανοίγει Pull Request αντί να γράφει απευθείας στο `main`.

Μετά την επιτυχή επεξεργασία δεν πρέπει να παραμένουν μη επεξεργασμένα αρχεία εδώ. Τα canonical Markdown αποθηκεύονται ως `sources/SRC-XXXXXXXXXX.md`, ώστε η μόνιμη δομή του repository να παραμένει σταθερή και ASCII-safe.
