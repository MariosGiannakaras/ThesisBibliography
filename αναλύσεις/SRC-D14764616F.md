# Context-Switching and Adaptation: Brain-Inspired Mechanisms for Handling Environmental Changes

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Eric Chalmers, Edgar Bermudez Contreras, Brandon Robertson, Artur Luczak, Aaron Gruber
- **Έτος:** 2016

- **DOI / arXiv / URL:** DOI:10.1109/IJCNN.2016.7727651

## Σκοπός και ερευνητικό ερώτημα

Η εργασία εξετάζει γιατί conventional model-based RL προσαρμόζεται αργά όταν αλλάζουν ξαφνικά transitions ή contingencies γνώριμου task. Προτείνει hierarchical state abstraction για γρήγορη προσαρμογή παλαιού model και context switching για αποθήκευση, αναγνώριση και επαναφορά πολλαπλών models περιβάλλοντος.

Η συνάφεια είναι ισχυρή: χρησιμοποιείται GridWorld, ο goal παραμένει σταθερός, αλλά οι διαδρομές και transition contingencies αλλάζουν επανειλημμένα. Αυτό αντιστοιχεί λειτουργικά στους «μεταβαλλόμενους κανόνες» της επίσημης αίτησης. Η πηγή δεν καθιστά το GridWorld επίσημη απαίτηση· τεκμηριώνει ότι αποτελεί κατάλληλο ελεγχόμενο testbed για repeated changes και model reuse.

## Σύνοψη

Μετά από αλλαγή περιβάλλοντος, παλιές value estimates και transition model μπορούν να παραπλανούν τον agent. Εμπόδια που υπήρχαν στο προηγούμενο maze παραμένουν στο model και η planning διαδικασία μπορεί να θεωρεί λανθασμένα ότι δεν υπάρχει route προς τον goal.

Η hierarchical representation ομαδοποιεί γειτονικές states σε macro-states. High-level value gradients επηρεάζονται λιγότερο από τοπικές αλλαγές και θέτουν subgoals, ενώ lower levels ανασχεδιάζουν τη διαδρομή. Το context-switching component διατηρεί recent transition history, αξιολογεί την πιθανότητά του υπό το current model και, όταν η συμβατότητα πέσει κάτω από threshold, επιλέγει αποθηκευμένο model ή δημιουργεί νέο.

Η αξιολόγηση συγκρίνει context switching με hierarchical adaptation, context switching χωρίς adaptation και conventional model-based RL σε οκτώ 16×48 GridWorlds. Κάθε environment χρησιμοποιείται για δέκα trials και η ακολουθία επαναλαμβάνεται. Το combined system επιτυγχάνει καλύτερη cumulative reward μέσω recall παλιών λύσεων και adaptation σχετικών models.

## Μεθοδολογία

- **Περιβάλλον:** οκτώ GridWorlds 16×48 με σταθερό goal και διαφορετικές wall/route contingencies.
- **Task sequence:** δέκα trials ανά environment· η ακολουθία επαναλαμβάνεται δύο φορές.
- **Termination:** goal ή 5.000 steps.
- **Rewards:** +10 goal, −0.1 wall, −0.01 άλλες transitions.
- **Agents:** conventional model-based RL, context switching, context switching με hierarchy/adaptation.
- **Planning:** prioritized sweeping και A* hierarchical planning.
- **Detection:** transition-history likelihood μήκους 20 και threshold 0.05.
- **Compute fairness:** έως 120 model updates ανά step και ισοδύναμο συνολικό hierarchy budget.
- **Repetitions:** 200· median cumulative reward με 25ο/75ο percentile.

## Κύρια ευρήματα

1. **Οι παλιές value gradients μπορεί να γίνουν ενεργά παραπλανητικές.** Παλιές barriers στο model μπορούν να κάνουν τη νέα route να φαίνεται αδύνατη και να απαιτούν random exploration για διόρθωση. Τεκμηρίωση: σελίδες 1–2, Figure 1.
2. **Detection και adaptation είναι ξεχωριστά components.** Το transition-history likelihood αναγνωρίζει model mismatch· κατόπιν απαιτείται recall, adaptation ή learning νέου model. Τεκμηρίωση: Sections II.B–II.C, Figure 5.
3. **Recurring context επιτρέπει ταχύτερη recovery μέσω recall.** Στη δεύτερη έκθεση, context switching επαναφέρει παλιές λύσεις αντί να ξεκινά από μηδενική γνώση. Τεκμηρίωση: σελίδες 6–7, Figures 7–9.
4. **Hierarchical adaptation βοηθά όταν υπάρχει κατάλληλο related model.** Coarse representations διατηρούν direction προς goal, αλλά το όφελος απουσιάζει όταν η library δεν έχει χρήσιμο starting point. Τεκμηρίωση: Sections II.A, IV και V.
5. **Repeated-environment protocol διαχωρίζει first adaptation, retention και recall.** Τεκμηρίωση: Section III και Figures 7–9.
6. **Η model library εισάγει failure modes.** Wrong context selection, duplicate models, memory growth και hierarchical suboptimality μειώνουν επίδοση. Τεκμηρίωση: Discussion.

## Υποθέσεις και ορισμοί

Κάθε configuration αντιμετωπίζεται ως context/MDP με κοινά state/action spaces και ίδιο goal. Η αλλαγή εντοπίζεται όταν recent transitions έχουν μικρή probability υπό το current model. Η recovery προκύπτει από:

- **recall:** επαναφορά ήδη μαθημένου model,
- **adaptation:** τροποποίηση παρόμοιου model,
- **relearning:** δημιουργία νέου model.

Οι κατηγορίες πρέπει να διαχωρίζονται. Recall γνωστού context δεν αποδεικνύει zero-shot adaptation σε άγνωστη αλλαγή.

## Περιορισμοί και απειλές εγκυρότητας

Η μέθοδος είναι tabular και βασίζεται σε spatial hierarchy προσαρμοσμένη σε GridWorld. Τα environments έχουν ίδιο goal και παρόμοια structure. Το planning είναι κυρίως deterministic. Hyperparameters ρυθμίστηκαν στα mazes A/B χωρίς sensitivity analysis. Δεν υπάρχουν σύγχρονα continual/meta-RL ή deep baselines.

Η hierarchy μπορεί να είναι suboptimal στο fine-grained MDP. Η library κλιμακώνεται άσχημα με πολλές μοναδικές αλλαγές και η selection μπορεί να δημιουργεί duplicate models. Η πηγή τεκμηριώνει scenario design και metrics, όχι καθολική υπεροχή context switching.
